🔤 中文字体效果预览

1. 微软雅黑 (Microsoft YaHei) 推荐
// 这是一段中文注释
const greeting = "你好，世界！";
console.log(greeting); // 输出: 你好，世界！
中文显示效果：笔画清晰，现代感强，适合屏幕阅读
2. 宋体 (SimSun)
// 这是一段中文注释
const greeting = "你好，世界！";
console.log(greeting); // 输出: 你好，世界！
中文显示效果：传统衬线字体，笔画有粗细变化，正式感
3. 思源黑体 (Source Han Sans) 推荐
// 这是一段中文注释
const greeting = "你好，世界！";
console.log(greeting); // 输出: 你好，世界！
中文显示效果：开源字体，多种字重，专业感强
4. 等距云 (LXGW WenKai) 文艺风格
// 这是一段中文注释
const greeting = "你好，世界！";
console.log(greeting); // 输出: 你好，世界！
中文显示效果：楷体风格，圆润柔和，适合长时间阅读
5. 系统默认 (sans-serif)
// 这是一段中文注释
const greeting = "你好，世界！";
console.log(greeting); // 输出: 你好，世界！
中文显示效果：使用系统默认字体，各平台略有不同
💡 选择建议：
• 追求现代感和清晰度 → 微软雅黑
• 追求专业感和可定制性 → 思源黑体（需安装）
• 喜欢柔和风格 → 等距云（需安装）
• 追求传统感 → 宋体
• 懒得装字体 → 系统默认（微软雅黑通常已内置）
