# Welcome to Snorkeling

Snorkeling is an open-source AI coding workspace built on top of [Wave Terminal](https://github.com/wavetermdev/waveterm). It keeps Wave's terminal, remote connection, file preview, editor, AI, widget, and layout foundations, then adds workflow features for day-to-day AI-assisted development.

The goal is simple: keep terminals, files, version control, and AI coding agents in one workspace so you switch windows less and keep more context attached to the work you are doing.

Check out [Getting Started](./gettingstarted) for installation instructions, or start with [Snorkeling Features](./snorkeling-features) to see what this fork adds.
