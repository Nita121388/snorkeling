Snorkeling is a modern AI coding workspace built on Wave Terminal. It includes a terminal, graphical widgets, file previews, remote connections, built-in editing, AI features, and Snorkeling-specific Agent and Sessions workflows.

### Download from GitHub Releases

Snorkeling release artifacts are published on the [Snorkeling GitHub Releases page](https://github.com/Nita121388/snorkeling/releases). Download the package that matches your platform.

<PlatformItem platforms={["mac"]}>

</PlatformItem>

<PlatformItem platforms={["windows"]}>

</PlatformItem>

<PlatformItem platforms={["linux"]}>

:::

## Core Concepts

### Tabs and Blocks

- **Tabs**: Like browser tabs, these help organize your work. Create new tabs with <Kbd k="Cmd:t"/>.
- **Blocks**: The building blocks of Snorkeling. A block can be a terminal, web browser, file preview, editor, AI panel, Sessions view, Version Control view, or another widget.
- **Layout**: Blocks can be dragged, dropped, resized, minimized, copied to other tabs, or moved into another window.

### Key Features

1. **Terminal Features**

   - Works with common shells such as bash, zsh, fish, PowerShell, and Git Bash.
   - Supports standard terminal behavior such as readline and control sequences.
   - Includes the `wsh` command for interacting with Snorkeling's GUI features.
   - Uses GPU acceleration on most platforms.

2. **AI Coding Workflows**

   - Launch Agent blocks from the current terminal, SSH connection, or Files path.
   - Browse local Codex and Claude Code session history in the Sessions view.
   - Resume supported sessions into new terminal blocks.
   - Configure Agent profiles through `settings.json`.

3. **Graphical Workspace**

   - Preview files such as images, video, Markdown, and syntax-highlighted code.
   - Browse web pages and use custom widgets.
   - Use Files workflows for copy, paste, rename, delete, path copying, and Agent launch.
   - Use Version Control blocks for Git/SVN status, diffs, history, commit, and sync actions.

4. **Remote Connections**

   - Connect to SSH hosts with the connection button <i className="fa-sharp fa-laptop"/>.
   - Use WSL integration on Windows.
   - Install the `wsh` helper on remote machines under `~/.snorkeling/bin/wsh` for richer remote widgets and commands.

## Quick Start Guide

1. **Open Your First New Tab**

   - New Snorkeling tabs start with a terminal block.
   - Use it like a regular terminal.
   - Create additional terminal blocks with <Kbd k="Cmd:n"/>.

2. **Try Some Basic Commands**

   ```bash
   # View a file or directory
   wsh view ~/Documents

   # Open a webpage
   wsh web open github.com

   # Get AI assistance
   wsh ai -m "how do I find large files in my current directory?" -s
   ```

3. **Launch an Agent**

   - Use the `Agent` sidebar entry to start an Agent from the current workspace context.
   - If several terminal or file contexts match, choose the intended one from the selector.
   - Configure default Agent behavior with `agent:defaultprofile` and `agent:profiles` in [Configuration](./config).

4. **Browse AI Sessions**

   - Open `Sessions` from the sidebar.
   - Filter Codex and Claude Code sessions.
   - Mark important sessions, add notes, copy session information, or resume a supported session.

5. **Connect to Remote Machines**

   - Click the <i className="fa-sharp fa-laptop"/> button.
   - Enter `username@hostname` for SSH connections.
   - Or select a WSL distribution on Windows.
