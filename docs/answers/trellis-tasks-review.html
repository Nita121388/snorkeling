python .trellis/scripts/task.py archive 10-28-aisessions-filter-presets
python .trellis/scripts/task.py archive 10-29-aisessions-open-sessions-ui
提示： 对于中等确定的任务，推荐先通过 git diff main...HEAD -- <相关文件> 对比实际改动，再决定是否归档，能够进一步降低误归档的风险。
