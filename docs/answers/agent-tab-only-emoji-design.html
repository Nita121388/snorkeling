Agent Tab「仅显示 Emoji」设计方案

在 Emoji Picker 中直接设置 · session 级存储 · 实时生效

1. 目标

在点击 Agent 图标打开的 AgentEmojiPicker 底部新增「仅显示 Emoji」开关。开启后，对应的 Inline Tab 只渲染 Emoji（或品牌 Logo），隐藏标题，仅保留状态元素。

2. 数据模型（推荐）

方案存储作用域评价
A. session 级（推荐）snorkeling:agent-tab-display-mode单个会话（sessionId）最贴合「仅此会话」心智，与 session-persona-store 同构
B. per-block metaagent:tab:emojionly单个 block 实例可行但关联不够自然
C. provider 级扩展 agent-personas整个 provider太粗

3. 文件改动清单

路径类型说明
frontend/app/agent-persona/tab-display-store.ts新增仿照 session-persona-store.ts 实现读写、订阅、跨窗口同步
frontend/app/view/term/agent-emoji-picker.tsx修改footer 新增「仅显示 Emoji」复选框，仅 sessionKey 非空时显示
frontend/app/block/block.tsx修改InlineTabLabel 用 useSyncExternalStore 订阅，条件隐藏标题并加 emoji-only class
frontend/app/block/block.scss修改新增 .inline-tab-block-tab.emoji-only 样式

4. 核心要点

  • 实时生效：切换后立即更新 Tab
  • 有图标才隐藏：agentIcon != null 时才应用
  • 保留状态：脏点、锁定、Agent 状态点、远程圆点都保留
  • 保留可访问性：aria-label 用完整标题，Tooltip 保留
  • 仅当有 sessionId 时显示开关
  • 与换 Emoji 独立，两者互不影响
