  • viewModel.viewText 返回 HeaderElem[]，承载标题和两个 chip。
  • viewModel.endIconButtons 增加搜索、星标、会话菜单，都放 pinned 区。

HeaderElem 已支持 text、input、iconbutton、menubutton，改名输入框和会话菜单都能直接放进框头。

两个硬约束要先解决：
