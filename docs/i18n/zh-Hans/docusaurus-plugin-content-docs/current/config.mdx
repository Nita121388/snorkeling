Wave 的配置文件位于 `~/.config/waveterm/`。

主配置文件是 `settings.json`（`~/.config/waveterm/settings.json`）。

该文件基本上是扁平结构的 JSON 文件。我们不使用子对象，而是更倾向于用 ":" 作为层级分隔符。

:::info

编辑配置文件最简单的方式是使用 `wsh editconfig` 命令，它会在 Wave 内置预览编辑器中打开你的 Wave 配置文件。

```
wsh editconfig
```

:::

## 环境变量解析

为了避免把密钥直接写入配置文件，Wave 支持使用 `$ENV:VARIABLE_NAME` 或 `$ENV:VARIABLE_NAME:fallback` 语法解析环境变量。这适用于任何配置文件中的任意字符串值（settings.json、presets.json、ai.json 等）。

```json
{
  "ai:apitoken": "$ENV:OPENAI_APIKEY",
  "ai:baseurl": "$ENV:AI_BASEURL:https://api.openai.com/v1"
}
```

## WebBookmarks 配置

WebBookmarks 允许你存储和管理网页链接，并自定义显示偏好。书签存储在 JSON 文件（`bookmarks.json`）中，形式为键值映射，其中键（`id`）是书签的任意标识符。按约定，id 应以 "bookmark@" 开头。在网页组件中，你可以使用 <Kbd k="Cmd:o"/> 调出书签。

### 书签结构

每个书签遵循以下结构（只有 `url` 必填）：

```json
{
  "url": "https://example.com",
  "title": "Example Site",
  "iconurl": "https://example.com/custom-icon.png",
  "display:order": 1
}
```

### 字段

| 字段          | 类型    | 说明                                                                                                              |
| ------------- | ------- | ----------------------------------------------------------------------------------------------------------------- |
| url           | string  | **必填。** 书签的 URL。                                                                                           |
| title         | string  | **可选。** 书签的显示标题。                                                                                       |
| icon          | string  | **可选，很少使用。** 用图标名称覆盖默认网站图标。                                                                 |
| iconcolor     | string  | **可选，很少使用。** 为指定图标设置自定义颜色。                                                                   |
| iconurl       | string  | **可选。** 提供自定义图标 URL；当网站图标不正确时很有用（例如为了兼容深色模式）。                                 |
| display:order | float64 | **可选。** 定义书签的显示顺序。                                                                                   |

### 示例 `bookmarks.json`

```json
{
  "bookmark@google": {
    "url": "https://www.google.com",
    "title": "Google"
  },
  "bookmark@claude": {
    "url": "https://claude.ai",
    "title": "Claude AI"
  },
  "bookmark@wave": {
    "url": "https://waveterm.dev",
    "title": "Wave Terminal",
    "display:order": -1
  },
  "bookmark@wave-github": {
    "url": "https://github.com/wavetermdev/waveterm",
    "title": "Wave Github",
    "iconurl": "https://github.githubassets.com/favicons/favicon-dark.png"
  },
  "bookmark@chatgpt": {
    "url": "https://chatgpt.com",
    "iconurl": "https://cdn.oaistatic.com/assets/favicon-miwirzcw.ico"
  },
  "bookmark@wave-pulls": {
    "url": "https://github.com/wavetermdev/waveterm/pulls",
    "title": "Wave Pull Requests",
    "iconurl": "https://github.githubassets.com/favicons/favicon-dark.png"
  }
}
```

### 行为

- 如果设置了 `iconurl`，会从指定 URL 获取图标，而不是使用站点默认网站图标。
- 书签会根据 `display:order`（如果提供）排序，否则按 id 排序。
- `icon` 和 `iconcolor` 很少需要，因为默认行为会获取站点的网站图标。
- 网站图标每 24 小时刷新一次

## 终端主题

用户自定义终端主题位于 `~/.config/waveterm/termthemes.json`。

该 JSON 文件是一个对象，每个子键定义一个主题。
可以右键单击终端标题栏，并从“主题”子菜单中选择条目来应用主题。也可以将主题应用到
块的元数据键 `term:theme`。这里使用 JSON 键值作为标识符。注意，为了获得最佳一致性，所有颜色都应使用 "#rrggbb" 或 "#rrggbbaa" 格式（aa = 透明度 alpha 通道）。

```
wsh setmeta this term:theme="default-dark"
```

以下是完整终端主题定义示例。所有内置主题都定义在这里：https://github.com/wavetermdev/waveterm/blob/main/pkg/wconfig/defaultconfig/termthemes.json （如果你想添加热门终端主题，请提交拉取请求！）

```json
{
  "default-dark": {
    "display:name": "Default Dark",
    "display:order": 1,
    "black": "#757575",
    "red": "#cc685c",
    "green": "#76c266",
    "yellow": "#cbca9b",
    "blue": "#85aacb",
    "magenta": "#cc72ca",
    "cyan": "#74a7cb",
    "white": "#c1c1c1",
    "brightBlack": "#727272",
    "brightRed": "#cc9d97",
    "brightGreen": "#a3dd97",
    "brightYellow": "#cbcaaa",
    "brightBlue": "#9ab6cb",
    "brightMagenta": "#cc8ecb",
    "brightCyan": "#b7b8cb",
    "brightWhite": "#f0f0f0",
    "gray": "#8b918a",
    "cmdtext": "#f0f0f0",
    "foreground": "#c1c1c1",
    "selectionBackground": "",
    "background": "#00000077",
    "cursorAccent": ""
  }
}
```

:::info

运行以下命令即可轻松打开 `termthemes.json` 配置文件：


## 可自定义的系统级全局热键 {#customizable-systemwide-global-hotkey}

Wave 允许设置自定义全局热键，用于从电脑上的任意位置打开你最近使用的窗口。它在 `settings.json` 文件中的名称是 `"app:globalhotkey"`，格式是一组由 `:` 字符分隔的按键名称。

### 示例

作为一个实际示例，假设你想使用 `F5` 作为全局热键。只需将 `"app:globalhotkey"` 的值设置为 `"F5"`，然后重启 Wave，即可让它成为你的全局热键。

作为一个不太常见的示例，假设你使用 `Ctrl`、`Option` 和 `e` 的组合。那么这个快捷键的值就是 `"Ctrl:Option:e"`。

### 允许的按键名称

支持以下按键名称：

- `Ctrl`
- `Cmd`
- `Shift`
- `Alt`
- `Option`
- `Meta`
- `Super`
- 数字键（非小键盘），表示为 `c{Digit0}` 到 `c{Digit9}`
- 字母 `a` 到 `z`
- F 键 `F1` 到 `F20`
- 软键 `Soft1` 到 `Soft4`。它们本质上等同于 `F21` 到 `F24`。
- 空格，表示为 `Space` 或字面量空格 &nbsp;<code>&nbsp;</code>
- `Enter`（在 Mac 上标为 Return）
- `Tab`
- `CapsLock`
- `NumLock`
- `Backspace`（在 Mac 上标为 Delete）
- `Delete`
- `Insert`
- 方向键 `ArrowUp`、`ArrowDown`、`ArrowLeft` 和 `ArrowRight`
- `Home`
- `End`
- `PageUp`
- `PageDown`
- `Esc`
- 音量控制 `AudioVolumeUp`、`AudioVolumeDown`、`AudioVolumeMute`
- 媒体控制 `MediaTrackNext`、`MediaTrackPrevious`、`MediaPlayPause` 和 `MediaStop`
- `PrintScreen`
- 小键盘数字键，表示为 `c{Numpad0}` 到 `c{Numpad9}`
- 小键盘小数点，表示为 `Decimal`
- 小键盘加号/加法，表示为 `Add`
- 小键盘减号/减法，表示为 `Subtract`
- 小键盘星号/乘法，表示为 `Multiply`
- 小键盘斜杠/除法，表示为 `Divide`
