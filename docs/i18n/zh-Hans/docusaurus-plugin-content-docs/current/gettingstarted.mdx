Wave Terminal 是一个现代终端，在传统终端功能之外，还包含网页浏览、文件预览和 AI 辅助等图形化能力。本指南会帮助你开始使用。

## 核心概念

### 标签页和块

- **标签页**：类似浏览器标签页，用来整理工作。使用 <Kbd k="Cmd:t"/> 创建新标签页。
- **块**：Wave 的基本工作单元。每个块都可以是终端、网页浏览器、文件预览或其他组件。
- **布局**：可以拖拽、放置和调整块大小，创建适合你的布局。

### 主要功能

1. **终端功能**

   - 支持常见 shell，例如 bash、zsh、fish
   - 支持标准终端功能，例如 readline、控制序列等
   - 包含 `wsh` 命令，可与 Wave 的 GUI 功能交互
   - 大多数平台支持 GPU 加速

2. **图形化组件**

   - 预览文件，例如图片、视频、Markdown、带语法高亮的代码
   - 浏览网页
   - 直接在终端中提问并获得 AI 帮助，也可以设置多个 AI 模型
   - 基础系统监控图表

3. **远程连接**
   - 使用连接按钮 <i className="fa-sharp fa-laptop"/> 轻松建立 SSH 连接
   - Windows 上支持 WSL 集成
   - 本地和远程会话体验一致

## 快速开始

1. **打开第一个新标签页**

   - 新的 Wave 标签页会从一个终端块开始
   - 像使用普通终端一样使用它
   - 使用 <Kbd k="Cmd:n"/> 创建更多终端块

2. **试几个基础命令**

   ```bash
   # 查看文件或目录
   wsh view ~/Documents

   # 打开网页
   wsh web open github.com

   # 获取 AI 辅助
   wsh ai -m "how do I find large files in my current directory?" -s
   ```

3. **自定义布局**

   - 拖拽块标题来重新排列
   - 悬停在块之间可调整大小
   - 右键点击标签页标题，可设置背景选项
   - 右键点击块标题，可查看该块专属选项

4. **连接远程机器**
   - 点击 <i className="fa-sharp fa-laptop"/> 按钮
   - 输入 `username@hostname` 建立 SSH 连接
   - 或在 Windows 上选择一个 WSL 发行版
