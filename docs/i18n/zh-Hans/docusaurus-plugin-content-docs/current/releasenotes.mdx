# 发布说明 {#release-notes}

## Snorkeling 发布 {#snorkeling-releases}

Snorkeling 从 `Nita121388/snorkeling` GitHub 仓库发布自己的 release，使用 `snorkeling-v...` tag。应用版本号包含 `snorkeling` 后缀。自动更新从 GitHub Releases 分发；更新错误会在 UI 中提示，应用会从 tag 推导版本号。

近期 Snorkeling 发布对应的功能集见 [Snorkeling 功能](./snorkeling-features)，以及 [Agent 工作流](./agent-workflow)、[AI 会话](./ai-sessions)、[版本控制](./version-control) 等专门页面。

Snorkeling 的发布线跟随 fork 自己的开发分支（`main`）。下面按版本从新到旧列出面向用户的主要更新。`0.0.36` 之前的版本因提交边界被合并/重放、在仓库中无法可靠拆分，按功能领域分组说明。

### 更早版本（0.0.1&ndash;0.0.36）&mdash; 功能领域

`0.0.39` 之前的版本奠定了 fork 的基础。其用户可见成果由以下功能领域概括（当前行为见 [Snorkeling 功能](./snorkeling-features)）：

- **Agent 工作流** – `Agent` 侧边栏入口、终端/Files 上下文继承、Agent profile（`agent:defaultprofile`、`agent:profiles`）与会话自动续接。
- **AI 会话** – `Sessions` 侧边栏入口、会话列表/详情/大纲、标记、备注、删除确认与恢复。
- **文件** – 目录树浏览、自然排序、路径复制/粘贴、定向打开、`Open VS Code Here`、`Copy Context`。
- **版本控制** – `VCS` 区块、变更分组、Diff/历史/提交、图形化提交与远程同步。
- **布局** – 区块最小化、跨标签页复制区块、`Move Tab to New Window`。
- **发布 / 更新** – `snorkeling-v...` tag 流水线、应用版本后缀与更新机制。

### 上游 Wave 历史 {#upstream-wave-history}

以下各节记录 Snorkeling 所基于的上游 Wave 发布历史。

### v0.14.5 &mdash; 2026 年 4 月 16 日

Wave v0.14.5 引入了新的进程查看器 widget、全局热键的 Quake Mode，以及多项体验改进。

- **进程查看器** - 新 widget，可显示本地和远程机器上正在运行的进程，包括 CPU 和内存使用率、可排序列，以及向进程发送信号的能力。
- **Quake Mode** - 全局热键 (`app:globalhotkey`) 现在会切换 Wave 窗口的显示和隐藏状态。
- **[bugfix] 设置 Widget** - 修复了尚不存在的配置文件无法通过 Settings widget UI 创建或编辑的问题。
- **拖放文件到终端** - 从 Finder (macOS) 或文件管理器将文件拖入终端 block，可粘贴其带引号的路径 ([#746](https://github.com/wavetermdev/waveterm/issues/746))。
- 新增可选的 `app:showsplitbuttons` 设置，可在 block 标题中添加水平/垂直拆分按钮。
- 可从 View 菜单切换 widgets 侧边栏；可见性按工作区持久保存。
- 按 F2 可重命名当前标签页。
- 鼠标按钮 3/4（后退/前进）现在可在 web widgets 中导航。
- 终端会话现在设置 `COLORTERM=truecolor`，为 CLI 工具提供更好的颜色支持。
- [bugfix] 从终端复制到剪贴板时移除末尾空白。
- 包和依赖升级。

### v0.14.4 &mdash; 2026 年 3 月 26 日

Wave v0.14.4 引入了垂直标签页，升级到 xterm.js v6，并包含一组 bug 修复和内部改进。

**垂直标签栏：**

- **新的垂直标签栏选项** - 标签页现在可以垂直显示在窗口侧边，让你获得更多水平空间，并在打开大量标签页时更容易访问。可在设置中切换水平和垂直标签页布局。

**终端改进：**

- **xterm.js v6.0.0 升级** - 升级到最新的 xterm.js v6，带来更好的终端兼容性和渲染效果。这应该能解决使用 Claude Code 等工具时观察到的多种终端渲染异常。

**其他变更：**

- **`backgrounds.json`** - 将 `presets/bg.json` 重命名为 `backgrounds.json`，并把背景配置迁移到新的 `tab:background` key（启动时自动迁移）。
- **配置错误移动** - 将配置错误从标签栏移到 Settings / WaveConfig 视图，减少界面杂乱。
- **未保存变更警告** - WaveConfig 视图现在会在丢弃未保存变更前发出警告。
- **流式传输性能** - 将文件流式传输迁移到带流控的新现代接口，修复了一个大型首字节延迟 bug。
- **macOS 首次点击** - 改进 macOS 上的首次点击处理（取消该点击，但正确设置 block/WaveAI 焦点）。
- 已移除旧版 AI widget。
- [bugfix] 修复新建 block 的焦点 bug。
- [bugfix] 修复通过拆分旧持久会话来启动新持久会话时的问题。
- Electron 升级到 v41。
- 包和依赖升级。

### v0.14.2 &mdash; 2026 年 3 月 12 日

Wave v0.14.2 添加了 block/标签页徽章、目录预览改进，以及若干 bug 修复。

**Block/标签页徽章：**

- **Block 级徽章，汇总到标签页** - Block 现在可以显示图标徽章（带颜色和优先级），并汇总显示到标签栏中，方便快速查看状态。
- **默认启用铃声指示器** - 终端铃声徽章现在默认开启，当终端响铃时会点亮 block 和标签页（由 `term:bellindicator` 控制）。
- **`wsh badge`** - 新增 `wsh badge` 命令，可从命令行设置或清除 block 上的徽章。支持图标、颜色、优先级、提示音，以及与 PID 关联、进程退出后自动清除的徽章。非常适合配合 Claude Code hooks，将通知显示到标签栏中（[文档](https://docs.waveterm.dev/wsh-reference#badge)）。

**其他变更：**

- **目录预览改进** - 改进修改时间格式、斑马纹行、更好的默认排序、YAML 文件支持，以及上下文菜单改进。
- **搜索栏** - 改进搜索栏中的剪贴板和焦点行为。
- [bugfix] 修复 GNOME 桌面上 "New Window" 卡住/无法工作的问题。
- [bugfix] 修复 "Save Session As..."（焦点窗口跟踪 bug）。
- [bugfix] 修复缩放变更通知没有正确发送到所有标签页的问题（布局不一致）。
- 在设置菜单中添加 Release Notes 链接。
- 正在开发 anthropic-messages Wave AI 后端（用于原生 Claude 集成）。
- 大量测试/mock 基础设施的内部工作，用于更快启用异步 AI 编辑。
- 文档更新。
- 包和依赖升级。

### v0.14.0 &mdash; 2026 年 2 月 10 日

**持久 SSH 会话和增强连接监控**

Wave v0.14 为 SSH 连接引入持久会话，让你的远程终端会话能够在连接中断、网络变化和 Wave 重启后继续存在。本版本还包含连接监控、带流控的 RPC 基础设施，以及扩展终端能力方面的重大改进。

**持久会话（仅远程 SSH）：**

- **在中断后继续存在** - SSH 终端会话会在网络变化、电脑睡眠和 Wave 重启后保持，并在连接恢复时自动重连。
- **会话保护** - 即使 Wave 关闭或断开连接，也会保留 shell 状态、运行中的程序和终端历史。
- **可视状态指示** - 终端标题中的盾牌图标会显示会话状态（Standard、Durable Attached、Durable Detached、Durable Awaiting），并提供详细悬浮信息。
- **灵活配置** - 可在全局、按连接或按 block 级别配置，并轻松在标准模式和持久模式之间切换。
- 设置和使用方式请参阅新的[持久会话文档](https://docs.waveterm.dev/durable-sessions)。

**增强连接监控：**

- **连接 Keepalive** - 主动监控 SSH 连接，并自动发送 keepalive 探测。
- **连接停滞检测** - 新连接监控器可在出现网络问题时检测并显示 "stalled" 连接状态，提供清晰的视觉反馈。
- **更好的错误处理** - 改进连接状态跟踪和面向用户的连接状态指示。

**终端改进：**

- **OSC 52 剪贴板支持** - 终端应用现在可以通过 OSC 52 转义序列直接复制到系统剪贴板。
- **增强上下文菜单** - 右键终端可快速访问拆分、打开 URL、主题、文件浏览器等功能。
- **简化标题布局** - 终端标题现在专注于连接信息，不再显示冗余的视图类型标签。

**Wave AI 更新：**

- **图像/视觉支持** - 为 OpenAI chat completions API 添加图像支持，使兼容模型具备视觉能力。
- **停止生成** - 新增能力，可在 OpenAI 和 Gemini 后端中途停止 AI 响应生成。
- **AI 面板滚动锁定** - 改进 Wave AI 面板中的自动滚动行为。
- **可配置详细程度** - 可控制 OpenAI Responses API 的详细程度级别。
- 弃用旧 AI-widget 代理端点。

**RPC 和性能：**

- **带流控的 RPC 流式传输** - 新增带内置流控的流式传输原语，提高性能和可靠性。
- **WSH Router 重构** - 重大路由架构改进，避免连接中断时卡住。
- **RPC 客户端/服务器清理** - 改进 RPC 实现和错误处理。

**配置更新：**

- **隐藏 AI 按钮** - 新增 `app:hideaibutton` 设置，可从 UI 隐藏 AI 按钮。
- **禁用 Ctrl+Shift 箭头** - 新增 `app:disablectrlshiftarrows` 设置，用于处理键盘快捷键冲突。
- **禁用 Ctrl+Shift 显示** - 新增 `app:disablectrlshiftdisplay` 设置，可禁用覆盖 block 编号显示。

**破坏性变更：**

- **移除固定标签页** - 已从 UI 中移除固定标签页功能。
- **移除 S3 和 WaveFile** - 移除 S3 文件系统和 wavefile 实现，以避免大型/递归文件传输问题并简化代码库。

**其他变更：**

- **退出确认** - 当 Wave 有活跃会话时，关闭应用会显示确认对话框。
- Monaco Editor 升级，移除 `monaco-editor/loader` 和 `monaco-editor/react` 依赖，以提升性能和稳定性。
- 新 Tab 模型和 React provider，改进状态管理。
- 移除 OSC 23198 和 OSC 9283 旧处理器。
- 更新贡献指南。
- Go 工具链升级到 1.25.6。
- 增强 OpenAI 兼容 API 提供商文档。
- [bugfix] 修复 sysinfo 视图中的空数据处理。
- [bugfix] 修复 Windows 上的 `app:ctrlvpaste` 设置（现在可以禁用）。
- [bugfix] 修复某些提供商下 Wave AI 系统提示词重复的问题。
- [bugfix] 修复断开连接卡住的问题，现在会立即断开。

### v0.10.0 &mdash; 2024 年 12 月 11 日

Wave Terminal v0.10.0 引入工作区，让管理多个工作环境更加容易。我们添加了强大的新命令执行能力 `wsh run`，允许你在专用 block 中启动和控制命令。本版本还通过新的 connections 配置系统显著改进 SSH，用于管理你的远程环境。

- **工作区**：将工作组织到独立环境中，每个环境有自己的标签页、布局和设置。
- **命令 Block**：新的 `wsh run` 命令，用于在专用 block 中启动终端命令，并支持放大、自动关闭和执行控制（[文档](https://docs.waveterm.dev/wsh-reference#run)）。
- **连接**：新的配置系统，用于管理 SSH 连接，支持无 wsh 操作、按连接主题等（[文档](https://docs.waveterm.dev/connections)）。
- 改进标签页管理，提供更好的切换行为和上下文菜单（大量 bug 修复）。
- 新标签页功能，包括固定标签页和拖放改进。
- 可直接在目录预览中创建、重命名和删除文件/目录。
- 如果 wsh 安装或执行失败，则尝试以无 wsh 连接作为回退。
- 为 `wsh ssh` 命令添加新的 `-i` 标志，用于添加 identity files。
- 添加 Perplexity API 集成（[文档](https://docs.waveterm.dev/faq#perplexity)）。
- `wsh setbg` 命令用于背景处理（[文档](https://docs.waveterm.dev/wsh-reference#setbg)）。
- 从 Less 切换到 SCSS 进行样式编写。
- [bugfix] 修复标签页切换期间标签页闪烁问题。
- [bugfix] 修正 WaveAI 文本区域调整大小行为。
- [bugfix] 修复并发 block controller 启动问题。
- [bugfix] 修复未初始化连接的 Preview Blocks。
- [bugfix] 修复无响应的上下文菜单。
- [bugfix] 修复 Help block 中的连接错误。
- Go 工具链升级到 1.23.4。
- 大量新文档，包括 [Getting Started](https://docs.waveterm.dev/gettingstarted)、[AI Presets](https://docs.waveterm.dev/ai-presets) 和 [wsh overview](https://docs.waveterm.dev/wsh) 的新页面。
- 其他 bug 修复、性能改进和依赖更新。

### v0.9.3 &mdash; 2024 年 11 月 20 日

新的小版本发布，引入 Wave 的 connected computing 扩展。我们引入了新的 `wsh` 命令，允许你存储变量和文件，并跨终端会话（本地和远程机器）访问它们。

- `wsh setvar/getvar` 用于获取和设置变量 -- [文档](https://docs.waveterm.dev/wsh-reference#getvarsetvar)。
- `wsh file` 操作（cat、write、append、rm、info、cp 和 ls）-- [文档](https://docs.waveterm.dev/wsh-reference#file)。
- 改进 golang panic 处理，防止后端崩溃。
- 改进 SSH 配置日志，并修复一个复用连接 bug。
- 更新遥测以跟踪额外计数器。
- 新配置设置（位于 "window:magnifiedblock" 下），用于控制放大 block 的边距和显示。
- 新 block/zone 别名（client、global、block、workspace、temp）。
- `wsh ai` 文件附件现在会在 AI block 中以特殊方式渲染。
- 新的 ephemeral block 类型，用于创建不会干扰底层布局的模态 widget。
- 从 Wave AI block 编辑 AI 预设文件现在会打开 ephemeral editor。
- 点击放大 block 外部现在会取消放大。
- 新按钮用于清空 AI chat（也绑定到 Cmd-L）。
- 新按钮用于重置自定义 cmd widgets 中的终端命令。
- [bugfix] presets 目录在 Windows 上加载不正确。
- [bugfix] 放大的 blocks 启动时显示不正确。
- [bugfix] 窗口透明度和背景色在某些情况下没有正确应用。
- [bugfix] 修复应用全局默认值时的终端主题 [#1287](https://github.com/wavetermdev/waveterm/issues/1287)。
- 不再支持 MacOS 10.15 (Catalina)。
- 其他 bug 修复、文档改进和依赖升级。
