# 工作区 {#workspaces}

工作区是一种强大的组织方式，可将工作流拆分到独立环境中，并按你的需要进行定制和优化。

## 工作区切换器 {#workspace-switcher}

![工作区切换器截图](./img/workspace-switcher.png#right)

与工作区交互的主要方式是使用位于标签栏左侧的工作区切换器。

你可以在这里创建新工作区、编辑工作区条目的显示方式，以及删除工作区。

工作区切换器按钮会显示当前活动工作区的图标和颜色。如果当前工作区尚未保存，它会显示 <i className="custom-icon-inline custom-icon-workspace"/> 图标。点击该按钮会打开工作区切换器。

切换器会列出当前安装中的所有已保存工作区，每个工作区都可以自定义图标、图标颜色和名称。

当前窗口正在使用的工作区旁边会显示 <i className="fa fa-sharp fa-check"/>。已经在其他窗口打开的工作区旁边会显示 <i className="fa fa-sharp fa-window"/> 图标。

将鼠标悬停在切换器中的某个工作区上，会显示 <i className="fa fa-sharp fa-pencil"/> 图标。点击后会打开编辑面板，你可以在其中修改工作区名称、图标和图标颜色，也可以从该面板删除工作区。

## 创建新工作区 {#creating-a-new-workspace}

每个新窗口都会初始化为一个空白工作区，其中包含一个标签页，标签页里有一个终端 block。创建新工作区有三种方式：

1. 通过应用的 `File` 菜单或[快捷键](./keybindings.mdx#global-keybindings)创建新窗口。这会创建一个新窗口，并在其中创建一个新工作区。
2. 通过应用的 `Workspace` 菜单创建新工作区。这会创建一个新工作区，并将当前窗口切换到该工作区。
3. 如果你当前位于已保存工作区，可以点击工作区切换器底部的 "Create new workspace" 按钮。这会创建一个新工作区，并将当前窗口切换到该工作区。

## 保存工作区 {#saving-a-workspace}

:::info

新工作区是临时的。窗口关闭时，如果工作区未保存，该工作区以及其中所有标签页都会被删除。

唯一的例外是最后一个窗口：无论该工作区是否已保存，关闭后都会被保留，并在下次打开应用时重新打开。

:::

要保留新工作区，必须先保存它。可以点击工作区切换器底部的 "Save workspace" 按钮完成保存。

如果你在工作区切换器底部看到的是 "Create new workspace"，说明你已经位于已保存工作区。也可以通过工作区切换器顶部的文字确认：未保存工作区会显示 "Open workspace"，已保存工作区会显示 "Switch workspaces"。此外，工作区切换器按钮显示 <i className="custom-icon-inline custom-icon-workspace"/> 图标时，也表示当前工作区尚未保存。

工作区保存后，你会在工作区切换器列表中看到一个新的已保存工作区条目。它会被命名为 `New Workspace (<random string>)`。为了更好地使用工作区，建议将名称、图标和图标颜色改成更容易记忆或更有意义的内容。

## 切换工作区 {#switching-workspaces}

切换工作区有两种方式：

1. 在已打开的窗口中打开工作区切换器，并点击列表中的某个工作区。
2. 在应用的 Workspace 菜单中点击列表里的某个工作区。

如果该工作区已经在另一个窗口打开（在工作区切换器中旁边会有 <i className="fa fa-sharp fa-window"/> 图标），那个窗口会获得焦点。

如果该工作区尚未打开，当前窗口会切换到它。如果当前工作区尚未保存，系统会询问你是要在新窗口中打开目标工作区，还是在当前窗口中打开。**如果选择后者，当前工作区及其内容会被删除。**

工作区切换器按钮会更新为新活动工作区的彩色图标。

## 编辑工作区 {#edit-a-workspace}

:::info

[已保存工作区](#saving-a-workspace)中的标签页、布局以及终端和 AI 历史会自动持久保存。不过，如果编辑器或网页中有未保存的文件更改，关闭窗口时这些进度会丢失。

:::

要更新工作区的名称、图标和图标颜色，请将鼠标悬停在工作区切换器中的该工作区上，然后点击出现的 <i className="fa fa-sharp fa-pencil"/> 按钮。这会打开编辑面板，你可以在其中修改设置。更改会自动持久保存并更新。
