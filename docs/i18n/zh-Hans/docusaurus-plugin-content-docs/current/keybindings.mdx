下面是 Wave 可用的默认快捷键集合，按部分划分。
有些快捷键始终生效，另一些只在特定类型的块中生效。

请注意，这些是 macOS 快捷键（使用 "Cmd"）。在 Windows 和 Linux 上，

:::note Snorkeling

Snorkeling fork 没有引入新的键盘快捷键。fork 专属工作流——[Agent 启动](./agent-workflow)、[AI 会话浏览](./ai-sessions)、[版本控制](./version-control)——都是通过右侧边栏入口访问，而不是专用快捷键。下面所有快捷键在 Snorkeling 中仍然有效。
:::
请将 "Cmd" 替换为 "Alt"（注意 "Ctrl" 在 Mac、Windows 和 Linux 上都是 "Ctrl"）。

连续快捷键会在按键之间用 + 显示。按下第一个键后，你有 2 秒时间按下第二个键。在按下连续快捷键的第一个键后按 Escape，始终不会执行任何操作。

## 文件预览快捷键

| 按键                                      | 功能                                                                                               |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| <Kbd k="[text]"/>                         | 任意普通字符（例如 "a"、"b"）都会筛选文件列表                                                    |
| <Kbd k="Escape"/>                         | 清除筛选                                                                                           |
| <Kbd k="ArrowUp"/> / <Kbd k="ArrowDown"/> | 向上/向下更改文件选择                                                                              |
| <Kbd k="Enter"/>                          | 打开当前选中的文件/目录                                                                            |
| <Kbd k="Cmd:ArrowUp"/>                    | 上移一级目录（父目录）                                                                             |
| <Kbd k="Cmd:ArrowLeft"/>                  | 后退，移动到之前选中的文件/目录                                                                    |
| <Kbd k="Cmd:ArrowRight"/>                 | 前进（与后退相反）                                                                                 |
| <Kbd k="Cmd:o"/>                          | 打开新文件（接受相对于当前目录的路径）                                                            |
| <Kbd k="Cmd:s"/>                          | 文件编辑器打开时，保存文件                                                                         |
| <Kbd k="Cmd:e"/>                          | 对于可预览或编辑的文件（Markdown、CSV），在预览和编辑模式之间切换                                 |
| <Kbd k="Cmd:r"/>                          | 文件编辑器打开时，还原更改                                                                         |

## 可自定义的系统级全局热键 {#customizeable-systemwide-global-hotkey}

Wave 允许设置自定义全局热键，用于从电脑上的任意位置聚焦你最近使用的窗口。更多信息参见[配置文档](./config#customizable-systemwide-global-hotkey)。
