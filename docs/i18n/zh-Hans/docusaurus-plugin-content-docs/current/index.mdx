# 欢迎使用 Wave Terminal

Wave 是一个 [open-source](https://github.com/wavetermdev/waveterm) 终端，把传统终端能力和文件预览、网页浏览、AI 辅助等图形化能力放在一起。它支持 macOS、Linux 和 Windows。

现代开发经常需要在终端和浏览器之间切换：查文档、预览文件、监控系统、使用 AI 工具。Wave 把这些图形化工具直接放进终端，让你可以通过命令行控制它们。这样你可以继续保持终端工作流，同时也能使用需要的可视化界面。

安装说明请查看 [入门指南](./gettingstarted)。
