# 欢迎使用 Snorkeling

Snorkeling 是基于 [Wave Terminal](https://github.com/wavetermdev/waveterm) 的开源 AI 编程工作流二次开发版。它保留 Wave 的终端、远程连接、文件预览、编辑器、AI、组件和布局基础，并在此之上加入更贴近日常 AI 辅助开发的工作流能力。

它的目标很直接：把终端、文件、版本控制和 AI 编程 Agent 放在同一个工作台里，让你少切窗口，并尽量保留当前工作的上下文。

安装请查看 [入门指南](./gettingstarted)。如果想先了解 Snorkeling 相比上游 Wave 增加了什么，请查看 [Snorkeling 功能概览](./snorkeling-features)。
