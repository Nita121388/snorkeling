交互说明

  • 点击下拉框中的 Edit SSH Config：右侧 Tab 新增一个 block（preview 视图 + edit: true）打开 ~/.ssh/config，可连续点击新增多个；
  • 切换「本地 / ssh myhost」后再次点击：新增 block 的 header 连接图标 / breadcrumb 区分文件来源；
  • 远程时后端按连接解析 ~（wavebase.ExpandHomeDirSafe），编辑的是远端文件；
  • 文件不存在时沿用 preview 的 File Read Failed 错误展示；
  • 下拉框无输入时才显示管理条目（与 Edit Connections 同条件）。

落地路线（只改一个文件）

  • frontend/app/modals/conntypeahead.tsx：新增 getSshConfigEditItem()，onSelect 时 createBlock({ view: "preview", file: "~/.ssh/config", edit: true, connection: … }) —— 与 Edit Connections 条目同模式（新增 block）；
  • 无需后端改动（FileRead/FileWrite 已支持 ~ 展开 + 远端透传）；
  • 完成后更新 docs/docs/connections.mdx 补充入口说明。
