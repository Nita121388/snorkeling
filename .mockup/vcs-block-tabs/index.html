VCS Block — 三 Tab 下拉面板

将 Version Control 下拉面板从单一文件列表改为 三 Tab 页面： 文件改动（当前功能）+ 分支（列表/切换/创建）+ 流水线（CI 运行）。 参考 Lyra GitPanel.tsx 的 Tab 结构，顶部常驻仓库头（分支名 + KPI + 同步按钮）。

设计说明

维度 当前 三 Tab 方案
面板结构 单一文件列表 + 折叠区 顶部仓库头 + 三 Tab（改动/分支/流水线）
分支信息 RepoHeader 文字显示，不可操作 独立 Tab：列表、切换、创建、ahead/behind
CI/CD 无 独立 Tab：运行列表、状态、耗时、展开详情
顶部同步 Pull 按钮在 RepoHeader 常驻 Fetch/Pull/Push 按钮 + KPI badge
文件操作 Diff/History 常驻 hover 浮现（120ms transition）
Tab 栏 无 图标 + 文字 + badge，参考 Lyra VIEWS[]
