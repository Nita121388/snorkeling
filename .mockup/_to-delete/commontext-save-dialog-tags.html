相对"上方 chip 行"的区别：胶囊紧贴 Text 框下沿，读起来像"Text 的标签摘要"而非"独立筛选行"，更贴近你说"在 Text 下渲染"的语义。

不做胶囊在 textarea 内就地渲染（方案 1B）：那需要把 textarea 替换成 contentEditable，重写光标 / 输入法 / 粘贴 / 换行，回归风险高，体验容易出脏。本方案借用已就绪的 SessionTagChips，零新增交互风险。
