视觉改动清单 (合入时只动 className,不动 props/state)：

  • subtitle — 字段值由 Snorkeling 改为 ↳ from «Snorkeling» Tab。在 MoveBlockToTabModal 里给 subtitle prop 拼前缀即可,
  • 列表行 hover 抬起按钮 — 原 TabTargetRow 右侧始终显示 {working ? workingLabel : actionLabel} 文字。改为:默认显示文字,:hover 时文字消失、显示同义的实色按钮。整行 click 仍是主触发路径,按钮只是视觉强调。
  • Move / Copy 按钮配色 — 二者都用 accent 主题色 (bg-action text-actiontext 风=实色 #58c142 / 深绿前景),只靠按钮文字 + 微图标(→ 表移动, ⧉ 表复制)区分动作。沿用项目 token,浅/深主题切换不裂。hover 用 bg-actionhover 加深,active 时 translateY(0.5px) 给轻按压反馈。
  • 按钮形状 — 高 26px,圆角 5px,字重 600,内边距 0 12px;图标与文字 5px 间距,图标 opacity 0.85 与文字保持层次。
  • working 行 spinner — 原 working 行右侧显示 "Moving..." 文字 + 整行 disabled。改为 14px accent spinner + 整行 opacity:.55。
  • 列表容器 — 原无 border 无背景,新加 border + bg-list + radius-8 + p-1,与 modal 主体形成层次。
  • 行距字号 — px-2 py-2 → px-3 py-2;tabId 文字 11px → 10.5px 更轻。

不动:Modal 组件、空态文案 "No other tabs"、Cancel 按钮位置、ESC 关闭、整行 click 选择 tab 的交互路径。

静态原型限制:spinner/按钮抬起是 CSS 演示。真组件里按钮与文字共存,需要靠 :hover CSS 控制 display,而非 React state。
