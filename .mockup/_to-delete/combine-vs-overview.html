Combine Dashboard 是什么？怎么用？

一张图说清楚 Combine Dashboard 的定位、交互方式和与 Overview 的关系
为什么需要 Combine Dashboard？
1
现状：SessionOverview 是跨 Tab 的全局视图
它遍历所有 tab 的所有 blocks，显示 session details、notes、tags、messages。信息丰富，但每次打开都要加载大量数据，且无法实时"瞄一眼"终端输出。
2
Combine Dashboard = 当前 Tab 的"实时仪表盘"
只关注当前 tab 的 terminal 和 agent，每 block 展示 实时缩略预览（通过 SubBlock 嵌入 xterm.js）。不用离开当前工作上下文就能看到所有会话的状态——哪个 agent 卡住了、哪个 terminal 在跑什么命令。
3
两者互补，不冲突
Combine 用于实时监控当前 tab · Overview 用于全局会话管理和回顾。两者通过跳转按钮互相链接。

Combine Dashboard 交互流程

STEP 1 打开/关闭
1
点击 Tab 栏的 Combine 按钮
按钮位于 Note 和 Overview 之间。点击后左侧 split 出一个 340px 宽的仪表盘面板，右侧原有 layout 不受影响。再次点击关闭仪表盘（block 隐藏到后台，不删除）。
2
面板自动列出当前 Tab 的所有 Terminal 和 Agent
按 Agents / Terminals 分组。Agent 卡片显示实时状态芯片（working/blocked/done/idle），Terminal 卡片显示当前目录（CWD）。
3
卡片主体 = 实时终端预览（SubBlock 嵌入）
通过 SubBlock 组件（现有机制，已在 TermVDomNode 中使用）嵌入完整的 xterm.js 实例，展示实时终端输出。预览区 min-height: 60px、max-height: 120px，内容实时刷新。
STEP 2 卡片操作
A
跳转到原始 Block（）
点击卡片底部跳转按钮 → 原始 block 聚焦并高亮闪烁（复用现有 BlockModel.setBlockHighlight() + 双层 refocusNode() 模式）。Dashboard 保持打开。
B
排除 Block（×）
hover 卡片可见右上 ×。点击后卡片从主体移到 Excluded 区，可点击恢复按钮撤回。排除列表持久化到 localStorage，跨重启保留。
C
在 Overview 中查看（）
仅 Agent 卡片显示。点击后打开 Overview 并自动定位到对应 block（调用 SessionOverviewModel.getInstance().open() 后跳转）。

与 Overview 的联动

跳转链路
Combine [ ] Overview 打开 → 自动定位到同一 block
Combine 当前 Tab · 实时预览 · 轻量
Overview 跨 Tab · session detail · notes · tags · 全局
排除状态共享
!
Overview 读取 Combine 排除列表
在 Overview 中，被 Combine 排除的 block 行会显示 "Excluded from Combine" 标签。但 Overview 不强制隐藏 — 用户可以在 Overview 中独立决定是否隐藏它们。
i
反向不共享
Overview 内的 agents-only 过滤、hide-unopened-tabs 等设置不影响 Combine Dashboard 的显示。

Combine vs Overview 快速对比

对比维度 Combine Dashboard SessionOverview
范围 当前 Tab 内 所有 Tab
内容 实时终端预览 + 状态芯片 session detail + notes + tags + messages
操作 跳转 / 排除 / 打开 Overview 编辑 note / 打 tag / 删除 session / 详细查看
数据量 极轻量（仅 status + 实时输出） 较重（加载 session cache）
排除持久化 localStorage，跨重启保留 隐藏 = hidden blocks（tab meta）

典型工作流

1
你在 snorkeling tab 里开了 3 个 terminal 和 2 个 agent
左侧 terminal 在跑 dev server，右侧 terminal 在 git status，中间 agent 在重构代码。
2
你点开 Combine Dashboard"瞄一眼"
看到重构的 agent 状态是 blocked（需要你 approve），dev server 正常运行。你的布局完全没变。
3
点击卡片跳转到 agent block，approve 之后继续
Dashboard 保持打开。之后你想回顾重构细节，点击 跳转到 Overview 查看完整 session messages。
