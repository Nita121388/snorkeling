Vendor selector · show 1 (current) + collapse the rest (+N▾)

Live behavior: when the New-Agent window opens, the `Vendor · from cc-switch` row lays out every vendor chip in a wrapping flex row. This mockup instead shows only the currently selected chip on one line plus a `+N▾` collapse toggle; clicking it reflows the rest in place. What's exposed is always the selected chip — if the official provider is selected, the official chip (with its official badge) sits on top and the rest collapse underneath.

Rules (maps to live widgets.tsx render site, lines ~700-765)
• Default visible chip = the currently selected one; effectiveSelectedVendorId != null uses it, otherwise fall back to vendor.is_current (identical to live line 720).
• Toggle text +N▾, where N = remaining vendor count. N=0 -> the toggle isn't rendered.
• Collapse/expand is pure frontend useState, local state (reset on window close, alongside the live "Reset the per-launch vendor pick" at lines 1434-1438).
• The expanded chips still render via the live effectiveVendorOptions.map(...); styles are fully reused — no border/panel/background between the current chip and the rest, they just reflow in place.
• The ·current and official badges and their colors are unchanged; only the default behavior stops laying every chip out at once.
