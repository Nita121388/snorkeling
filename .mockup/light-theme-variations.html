浅色主题变体方案

本页面展示浅色主题变体方案：方案 1~11 为原央视风格及备选方案；方案 12~37 为源自 dnakov/litter 项目的 26 个浅色主题（基于其 VS Code 格式主题 JSON 与 manifest 索引渲染）；方案 38~44 为基于米黄背景（#faf7f0）自定的 7 个补充方案（含 Snazzy 绿、橄榄绿、Obsidian 紫、灰紫，以及 3 种低饱和绿）。每个方案均展示主要 UI 组件：Icon、代码编辑器、Terminal、Tooltip、按钮、开关、调色板等。
