● Block Header — 点击路径 / Agent 名称切换

点击路径区域 → 弹出 Terminal 浮窗（同右键浮窗），快速切换 cwd 或 connection。
Agent Header Agent 名称 + 路径可点击

点击 codex Agent 标签 → 弹出 Agent 浮窗（同右键浮窗），可切换 provider 或路径。
点击路径 → 同上。
交互规则总结
点击 Widget → 单 target 直接创建，多 target 弹出浮窗
右键 Agent Widget → 弹出 Agent 浮窗（选类型 + 选路径，一个弹窗完成）
右键 Terminal Widget → 弹出 Terminal 浮窗（只选路径）
Header 点击 → 弹出对应浮窗（复用同一组件），快速切换
改动范围 全部在 FE（widgets.tsx + blockframe-header.tsx + term-model.ts），Go 后端无改动
