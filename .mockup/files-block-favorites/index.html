Design Specification — New Files Floating Window

角色：这个浮窗是 Files Block 的「打开 / 定位」入口（对齐 New Agent / New Terminal 的 launch target 窗口）。它管三件事： ① 置顶目录 Pinned（用户主动固定、快捷跳转）· ② Recent（自动追踪）· ③ 当前 Tab 默认路径（行内 ✓ 勾选，对齐 New Agent）。

Trigger

Files Block folder icon click（替换当前 longClick context menu）→ 居中弹出 NewFilesFloatingWindow。

默认路径 — 行内 ✓ 勾选（per-tab）

规则：默认不在独立区设置，而在任意 Pinned / Recent 行上通过 DefaultCheckButton（✓）勾选。 对齐 New Agent 的 AgentDefaultLaunchTargetMetaKey 交互：勾选 = 设为当前 Tab 默认；再次点击 = 取消（toggle）。
全局默认（未设 Tab 的兜底）在通用 Settings → Files → Default root 中配置，不放在本浮窗内。
级别语义存储对齐
Tab 级（本浮窗 ✓ 勾选）当前 Tab 的 Files 打开根UpdateObjectMeta(tab, { "preview:explorer-root": pathKey })AgentDefaultLaunchTargetMetaKey
全局级（Settings 页面）「未手动设默认」的 Tab 打开于此settings.json preview:default-rootPreviewDefaultOpenTargetSettingKey
解耦规则：设默认不要求先置顶；置顶不等于默认；移除置顶不会动 Tab 默认。 解析顺序：Tab meta → 全局 preview:default-root → 系统兜底。

Data Model

  • "preview:pinned-directories" — Array<{ path: string, label?: string, addedAt: number }>，settings.json（置顶目录列表）
  • Tab 级默认 — per-tab meta：UpdateObjectMeta(tab, { "preview:explorer-root": pathKey })（复用既有 PreviewExplorerRootMetaKey）
  • Recent — Map<string, number> 前端 session 内内存追踪，不持久化

Interaction

  • Click folder icon → toggle NewFilesFloatingWindow (居中弹窗)
  • Click backdrop / press Esc → close
  • Click row → navigate in current block
  • Hover row → ✓ (DefaultCheckButton) → toggle set as this tab's default
  • Hover row → × → unpin / clear from recent
  • "Add current dir" → pin current path
  • Footer "Current" → pin + set as this tab's default
  • Footer "New" → open selected in new Files block
  • Footer "Existing…" → open pick-a-target dialog for existing tab
  • Right-click dir → "Pin" / "Unpin" / "Set as Tab Default"
