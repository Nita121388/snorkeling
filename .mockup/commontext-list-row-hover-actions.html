🎨 设计规范

按钮顺序：Edit → Send → Copy → [sep] → Delete
悬浮触发：默认 opacity:0，hover 时 opacity:1，过渡 150ms
Send 禁用：无聚焦 terminal 时 disabled + cursor:not-allowed
Delete 悬停：高亮 error 色 + 微红背景
事件阻止：所有 action 按钮必须 event.stopPropagation()
分隔线：Copy 与 Delete 之间用 1px 竖线分隔

🔧 按钮排列变体

方案 A：Edit / Send / Copy / Delete（推荐）
npm run dev
npm run dev -- --port 3000
方案 B：Copy / Edit / Send / Delete（Copy 优先）
npm run dev
npm run dev -- --port 3000

📋 技术实现要点

1. CSS 核心
.actions-col 默认 opacity:0，.list-item:hover .actions-col 时 opacity:1
过渡时间 transition: opacity 0.15s ease

2. 事件处理
每个按钮 onClick 必须 event.stopPropagation()

3. Send 可用性
复用 focusedTermBlockIdAtom，disabled 时用 <span> 包裹以支持 tooltip

4. Delete 确认
沿用 window.confirm("Delete this common text?")
