Widget Quick Launch — 键盘快捷启动面板

结构镜像真实 frontend/app/workspace/widgets.tsx（WidgetsBar 点击 = createBlock） + inlinetab-addmenu.tsx（widget 注册表驱动菜单）+ keymodel.ts（全局快捷键） + inlineTabs.ts / layoutModel.addBlockToInlineTab（Blocks 组）。 新增文件 widget-quick-launch.tsx（计划中）。

设计定稿：按 Cmd/Ctrl+Shift+p 弹居中浮层，列出全部 supported widget（无搜索框——目前 widget 仅几个）； 点一个 widget → 底部出现两个放置按钮 [New Block] / [Current Group]。 New Block = 当前 Tab 新建兄弟 Block；Current Group = 加入当前 focused Block 所在组、成为新 Tab （单 Block 节点会被 addBlockToInlineTab 自动升级为组）。 Terminal / Agent 同样走两选放置，经 requestLaunchPopup 唤起现有目标选择浮窗（sink 改道进组）。

按快捷键或点按钮打开 · 列表无过滤框（widget 数量少） 提示：面板上 ↑↓ 移动 · Enter 选中 · Esc 关闭
当前 Tab 布局 — focused = 高亮块（点 block 切换 focus）
ⓘ New Block：在当前 Tab 追加一个兄弟 pane（等同现在点右侧 WidgetsBar）。
ⓘ Current Group：focused 是组 → 追加为新 Tab；focused 是单 Block → 自动升级为组（原块 + 新块两 Tab）。
设计要点
  • 触发：keymodel.ts 新增 Cmd:Shift:p → openWidgetQuickLaunch()（对标现有 openCommonTextSearch）。
  • 数据源：与 WidgetsBar / 组「＋」菜单同源 —— pickGroupAddableWidgets(fullConfig.widgets, workspaceId)；用户自定义 widget 自动出现。
  • 无搜索框：widget 数量少，直接列表；点选为主，轻量 ↑↓/Enter 键盘导航。
  • 两选放置：底部 [New Block] / [Current Group]。Current Group 调 layoutModel.addBlockToInlineTab(focusedNodeId, blockId)。
  • Terminal/Agent 二级弹窗：选 widget → 底部 [New Block]/[Current Group] → 点击后打开二级弹窗（New Agent / New Terminal 目标选择器：profile 选择 · path 列表 · Env · 底部确认），placement 作为 sinkNodeId 带入；确认后 CreateBlock + addBlockToInlineTab(Current Group) / createBlock(New Block)。与右栏 WidgetsBar 同款弹窗。
  • 不改：addBlockToInlineTab / requestLaunchPopup / 布局模型 / Agent·Terminal 浮窗 —— 全复用。
