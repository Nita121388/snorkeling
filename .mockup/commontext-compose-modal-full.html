📋 完整交互设计规范

1. 按钮顺序（方案A）：Edit → Send → Copy → [分隔线] → Delete
2. 悬浮触发：actions-col 默认 opacity:0，group-hover 时 opacity:1，过渡 150ms ease
3. Send 禁用：无聚焦 terminal 时 disabled + cursor:not-allowed，tooltip "Focus a terminal to enable Send"
4. 事件阻止：所有 action 按钮必须 event.stopPropagation()，防止触发行 onClick（插入 editor）
5. 编辑入口：推荐用 Save Dialog 覆盖（方案6），保持 Compose Modal 层级不深入；备选行内编辑（方案2）
6. Delete 确认：沿用 window.confirm("Delete this common text?")
7. 键盘导航：↑↓ 切换选中行，Enter 插入 editor，Escape 关闭弹窗
8. 状态反馈：Copy/Send/Delete 操作后状态行显示结果（ok/err/info）
9. 标签筛选：点击 chip 切换筛选状态，选中态 accent 底色

🎨 视觉设计决策

色彩体系：沿用 Snorkeling 暗色主题 — bg:#222, modal:#2a2a2a, accent:#58c142, error:#e54d2e
按钮尺寸：action-btn 22×22px，图标 11px，圆角 5px
分隔线：Copy 与 Delete 之间 1px 竖线，降低误触风险
选中态：列表行 active/hover 背景 var(--hover-bg) = rgba(255,255,255,0.06)
标签 chips：高度 24px，圆角 6px，无描边，选中态 accent 底色
编辑器：monospace 字体，深色背景，聚焦时 accent 边框
