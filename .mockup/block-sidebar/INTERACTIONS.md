# Block Sidebar — 交互设计

> 补充原型交互细节：预览、删除、恢复、批量操作、键盘快捷键。

---

## 1. Hover 行为层级

```
鼠标移入 icon：
├── 第一层：Tooltip（标题 + 路径）     ← 立即显示
├── 第二层：Hover 操作栏（预览/恢复/删除） ← 延迟 300ms 显示，避免误触
└── 第三层：预览浮窗（内容缩略图）       ← 延迟 600ms 显示，可被操作栏打断
```

### 时序图

```
鼠标进入 icon 区域
  │
  ├─ 0ms    → 显示 Tooltip
  ├─ 300ms  → icon 右侧浮现操作栏 [👁][↗][×]
  │            └─ 若鼠标在 300ms 内离开 → 不显示操作栏
  ├─ 600ms  → 若鼠标仍在 icon 上且未点击操作栏 → 弹出预览浮窗
  │            └─ 预览浮窗跟随鼠标位置
  │            └─ 鼠标移入浮窗 → 保持显示
  │            └─ 鼠标移出 icon + 浮窗 → 延迟 400ms 关闭
  │
  鼠标离开 icon 区域
    ├─ 操作栏：立即隐藏
    ├─ Tooltip：立即隐藏
    └─ 预览浮窗：延迟 400ms 关闭（可被 mouseenter 打断）
```

### Hover 操作栏

```
┌──┐  ┌─────┐
│📄│→ │👁 ↗ ×│  ← 三个操作按钮，水平排列
└──┘  └─────┘
      ↑
      操作栏在 icon 右侧弹出，不遮挡其他 icon

  👁 = 预览（打开临时视图）
  ↗  = 恢复（放回布局）
  ×  = 删除（需确认）
```

### 预览浮窗

```
┌─────────────────────────────┐
│ 📄 README.md           [↗] │  ← 标题栏 + 恢复按钮
│ /code/snorkeling/README.md  │  ← 路径
├─────────────────────────────┤
│ # Snorkeling                │
│                             │
│ A terminal-based AI coding  │  ← 内容缩略图（前 8 行）
│ assistant...                │
│                             │
│ [截断提示：显示前 8 行]       │
├─────────────────────────────┤
│ [恢复到布局]    [删除]       │  ← 底部操作栏
└─────────────────────────────┘

位置：icon 右侧弹出（空间不足时左侧）
宽度：320px
高度：max 280px（内容区限高）
```

## 3. 删除确认

### 方案 A：内联确认（推荐）

点击 × 或右键删除后，icon 变为确认状态：

```
正常状态：           确认状态：
┌──┐                ┌──┐
│📄│                │⚠ │  ← icon 变为警告图标
└──┘                └──┘
                     ↓
                    [✓][×]  ← 两个小按钮：✓确认 / ×取消

再次点击 ✓ → 执行删除
点击 × 或 2秒无操作 → 恢复正常状态
```

**优点**：不打断工作流，不弹模态框
**缺点**：误触风险略高（但有 2 秒超时回退）

### 方案 B：Toast 确认

```
┌──────────────────────────────────┐
│ 🗑 删除「README.md」？            │
│                    [取消] [删除]  │  ← 底部 Toast
└──────────────────────────────────┘
```

**优点**：明确，不易误触
**缺点**：打断工作流

### 方案 C：拖拽到删除区

```
┌──┬────────────────────────────┐
│📄│                            │
│💬│      拖拽 icon 到底部       │
│──│                            │
│⚙ │   ┌──────────────────┐    │
│ ＋│   │ 🗑 拖到这里删除    │    │  ← 底部出现删除区
│  │   └──────────────────┘    │
└──┴────────────────────────────┘
```

**优点**：符合直觉，适合批量删除
**缺点**：需要拖拽支持，实现复杂度高

**推荐**：Phase 1 用方案 A（内联确认），Phase 4（拖拽定位）时加方案 C。

## 4. 预览的两种语义

### 4.1 临时预览（Hover 浮窗）

- 不影响布局，不创建新节点
- 仅显示内容缩略图（前 8 行）
- 关闭后无残留
- 适合：快速确认 Block 内容

### 4.2 完整预览（Ephemeral Node）

- 调用 `layoutModel.newEphemeralNode(blockId)`
- 在布局中创建临时视图，关闭后不删除
- 适合：需要仔细查看内容
- 触发方式：操作栏的 👁 按钮 / 右键菜单「预览」

```
临时预览 vs 完整预览：

  临时预览（Hover 浮窗）          完整预览（Ephemeral Node）
  ┌──────────────────┐          ┌──┬──────────────────────┐
  │ 📄 README.md     │          │📄│ # Snorkeling         │
  │ # Snorkeling     │          │  │ A terminal-based...  │
  │ (前 8 行)         │          │  │ ...                  │
  └──────────────────┘          │  │ (完整内容，可滚动)     │
                                └──┴──────────────────────┘
  不占布局                      占布局，关闭后回到 sidebar
  无状态残留                    无状态残留
```

## 5. 批量操作

### 5.1 多选

- `Ctrl/Cmd + 点击` → 切换选中状态
- `Shift + 点击` → 范围选中
- 选中后 icon 高亮（accent 边框）

```
┌──┐
│💼│  ← 未选中
│📄│  ← 选中（accent 边框）
│💬│  ← 选中（accent 边框）
│──│
│⚙ │
└──┘
```

### 5.2 批量操作栏

选中 ≥ 2 个 icon 后，底部出现批量操作栏：

```
┌──┐  ┌──────────────────────────┐
│💼│  │ 已选 2 项  [恢复][删除]   │
│📄│  └──────────────────────────┘
│💬│
│──│
│⚙ │
└──┘
```

### 5.3 全选

- `Ctrl/Cmd + A` → 全选 sidebar 内所有 Block
- 再次 `Ctrl/Cmd + A` → 取消全选

## 7. Blocks 组交互

### 7.1 展开/折叠

```
折叠态：                展开态：
┌──┐                   ┌──┐
│💼│                   │💼│
│📄│                   │📄├──────┐
│ ▶│ ← 点击展开         │ │ tab1 │
│──│                   │ │ tab2 │
│⚙ │                   │ │ tab3 │
└──┘                   │──│     │
                       │⚙ │     │
                       └──┴─────┘
```

### 7.2 组操作

| 操作 | 方式 | 效果 |
|------|------|------|
| 展开/折叠 | 点击组 icon | 切换展开状态 |
| 恢复整个组 | 右键 → 恢复整个组 | 组内所有 Block 恢复到布局 |
| 解散组 | 右键 → 解散组 | 删除组，保留 Block（变为独立 icon） |
| 删除整个组 | 右键 → 删除整个组 | 删除组 + 组内所有 Block（需确认） |
| 拖拽 Block 到组 | 拖拽 icon 到组 icon | Block 移入组 |
| 拖拽 Block 出组 | 从展开的组拖出 | Block 移出组，变为独立 icon |

### 7.3 组内排序

- 展开组后，拖拽组内 icon 可调整顺序
- 顺序持久化到 workspace meta

## 9. 与现有功能的衔接

### 9.1 最小化入口

当前入口：Block header 右键菜单 →「Minimize to Float」

新入口（保留）：
- Block header 右键菜单 →「Minimize to Sidebar」
- Block header 按钮 → 新增「最小化到侧栏」图标按钮
- 快捷键（可选）：`Ctrl/Cmd + M`

### 9.2 恢复入口

- Sidebar 内：点击 icon / 操作栏 ↗ / 右键 → 恢复
- 布局内：无变化（Block 正常显示时不在 sidebar 中）

### 9.3 与 Inline-Tab Group 的衔接

```
最小化单个 Block：
  Block → 单个 icon

最小化 Inline-Tab Group（整个组）：
  Group → 文件夹式 icon
  ├── tab1
  ├── tab2
  └── tab3

最小化组内单个 Block：
  右键组内 tab → 「从组中最小化」
  → 该 Block 从组中移除，变为独立 icon
  → 组内剩余 Block 保持组结构
```
