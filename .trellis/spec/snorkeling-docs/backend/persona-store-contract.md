# Persona 存储契约（A1 数据地基）

> 代码：`pkg/persona/`、`cmd/wsh/cmd/wshcmd-persona.go`
> 设计：`design/plans/persona-system.md` §3.1 / §3.2 / §3.6 / §4.5
> 实现事实：`docs/project/persona-system.md`

## 不变量（改代码前先读）

1. **目录名 = id，写死。** 显示名只存 `persona.json.name`；改 id 必须走
   `wsh persona rename`（move + 重写 `persona.json.id` + 重生成名册）。任何别的路径改 id
   都会断开名册与跨机引用。
2. **单一真源。** `CHARTER.md` + `MEMORY/` 是唯一真源；`agents/*.md` 与根级 `AGENTS.md`
   是生成物（带 `GENERATED by wsh persona` 头），登场时幂等重建。不要手写进生成物。
3. **记忆纯 Markdown，不进 DB。** 包内只 import 标准库；名册是派生缓存
   （`.index/PERSONAS.md`），删掉可重建。
4. **写入纪律与 `wsh agent card` / `wsh data` 同款：**
   - 写命令默认 dry-run，`--yes` 才落盘；dry-run 必须零副作用（不建目录、不写名册）
   - 幂等：已存在 slug → 读回、零写入、退出码 0
   - `--json` 只输出一个结构化对象
5. **名册是注入面，不是展示面。** 每行 `emoji id | role | provider/model | ./id`；
   显示名不进名册（token 预算）。名册写入用临时文件 + `os.Rename` 原子替换。
6. **归档也是记忆的一部分。** `MEMORY/archive/` 随 git 同步；`work/` 与
   `*.local.json` 不同步（`.gitignore` 由 scaffold 生成）。
7. **scope 门词表。** `persona.Scope = "data"` 是写操作的 scope 级别；A1 只有本地人类
   CLI，真正的强制点在 A2.5（`agentscope.commandScopes` + `agentguide` 的 MCP 工具）。
   不要在 A1 往 `commandScopes` 塞不存在的 command（假门）。

## 判据口径

```bash
go test ./pkg/persona/...
go build ./cmd/wsh/
wsh persona create --name smoke --root /tmp/p --dry-run   # 0 落盘
wsh persona create --name smoke --root /tmp/p --yes       # .persona/ >= 9 文件
wsh persona rename smoke second --root /tmp/p --yes       # 旧目录消失、名册 0 引用
```
