# AI 会话子会话折叠：默认折叠 + 一键展开 + 视觉优化

## 背景

`10-21-aisessions-subagent-tree` 已经实现了父子树的数据与渲染，但列表层还缺两件事：

1. 没有全局「一键展开 / 全部收起」，只能逐个父行点箭头；父行多时无法一次看全。
2. 父子两级的视觉层级太弱：子行缩进线与父行折叠箭头不在同一条轴上，同一子行还
   同时存在 gutter 竖线和 content 左边框两条线；父子行字重、底色几乎相同。

本机索引实测（2026-10-23）：452 个子会话 / 65 个父会话 / 单父最多 107 个子会话。

## 目标

1. **默认折叠**：新装、清空 localStorage、或点「全部收起」后，所有父行都是收起态。
2. **一键展开 / 全部收起**：工具栏一个按钮完成，状态可回到手动模式。
3. **视觉层级重做**：父行读作「组头」，子行读作「组内条目」，一条连接线，无重复线。

## 非目标

- 不改后端与数据模型（`parentKey` / `kind` 已就绪）。
- 不改详情面板里的子代理卡片。
- 不做多级（> 1 层）折叠；磁盘结构本身只有一层父子。

## 现状行为（取证）

| 项 | 现状 | 位置 |
|---|---|---|
| 默认展开集合 | `[]`（即全部折叠） | `session-group.tsx:37` `readExpandedParents` |

## 需求

### R1 默认折叠（回归保证）

- 无 localStorage 记录时，全部父行收起，只显示计数徽标。
- 「全部收起」必须同时清空 localStorage 的 `aisessions.expandedParents`，并压制筛选自动展开。

### R2 一键展开 / 全部收起

- 工具栏新增一个按钮，放在「展开全部标签」按钮左侧。
- 语义：
  - 当前不是全部展开 → 点击 = 全部父行展开。
  - 当前全部展开 → 点击 = 全部父行收起，并回到默认折叠。
  - 当前部分展开（手动展开过几个）→ 点击 = 补齐为全部展开。
- 用户单独点某个父行箭头后，全局状态回到手动模式（不再被全局 override 覆盖）。
- 没有任何父行时按钮 disabled。
- 一键展开**不落盘**：刷新后仍由 localStorage 决定，避免把「全部展开」变成新默认。
- 一键展开**只展开一层**，不自动点 `Show all N sub-sessions`（保住 20 行上限）。

### R3 视觉层级

- 子行只有一条连接线，且与父行折叠箭头同轴（父行箭头中心 x≈20px）。
- 连接线用「竖线 + 短肘」表达归属；一组内最后一条子行用收尾肘（不再继续向下延伸）。
- 父行：标题 `font-medium text-primary`，展开箭头独立 20×20 热区、带 hover 底色与旋转动画。
- 子行：标题 `text-secondary`（hover 为 `text-primary`），字号比父行小一号；不额外加深底色。
- 计数徽标：折叠时显示 `N`；展开后隐藏（状态已由箭头表达），减少噪音。
- 展开的一组整体有极淡的背景包裹，读作一个块。

### R4 无回归

- 筛选命中子会话时仍然自动展开对应父行。
- `Show all N sub-sessions` 逻辑不变。
- 项目分组 / 时间分组两种模式都生效。
- 选中高亮、Mark、Resume、双击开详情、Ctrl+点击新开详情块全部不变。

## 验收标准

1. 清空 localStorage 后打开列表：所有父行折叠，只显示计数徽标，无子行。
2. 点一次全局按钮：65 个父行全部展开，子行缩进 + 连接线正确，箭头旋转。
3. 再点一次：全部收起，`localStorage["aisessions.expandedParents"]` 为 `[]`。
4. 手动展开 2 个父行后点全局按钮：补齐为全部展开；再点回到全部收起。
5. 带搜索词命中某个子会话：该父行自动展开，且其 `N/M` 高亮徽标保留。
6. 展开状态下列表 60s 自动刷新不会把收起的父行重新撑开。
7. 视觉：子行区域只有一条竖线，无第二条 content 左边框；子行标题弱于父行标题。

## 风险

- 一次展开 65 个父行、最多 452 个子行：保留 20 行上限后单次渲染 ≤ 452 行，可接受；
  若实测卡顿，退回「虚拟滚动」另开任务。
- `data-depth` / `:last-child` 选择器依赖 `renderNode` 的 DOM 结构，改动时要同步更新测试。
