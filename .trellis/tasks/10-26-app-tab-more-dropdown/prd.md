# Tab 栏「更多」下拉：Tab 过多时免滚动查找（垂直 + 水平）

## Goal

Tab 数量变多之后，用户不想靠在 Tab 栏里滚动 / 悬停展开去找目标 Tab。
垂直 Tab 栏和水平 Tab 栏都增加一个常驻的「更多」入口：点开即为**全量 Tab 下拉列表**，
支持搜索、切换、就地关闭，免去滚动查找。

## Context

- 两套 Tab 栏实现并存，由设置 `app:tabbar` 切换：`top`（水平 `tabbar.tsx`）/ `left`（垂直 `vtabbar.tsx`）。
- 两者现在都把「本次启动未打开、非激活、无未读点」的 Tab 折叠隐藏，只在 hover 时才展开：
  - 垂直：`max-h-0` 隐藏（`vtabbar.tsx` `isHidden`）。
  - 水平：从 `visibleTabIds` 里过滤掉（`tabbar.tsx` `visibleTabIds`）。
- 水平栏溢出策略是压窄到 `TabMinWidth` 后走 `OverlayScrollbars` 横向滚动，**没有"还有哪些 Tab"的入口**。
- 两栏各自复制了一份 `isActive / wasOpenedThisLaunch / hasUnreadDots` 判定，本次要收敛成一份共用逻辑。

## Requirements

### R1 「更多」入口（两种方向都要有）

- 垂直栏（`app:tabbar=left`）：底栏改为左右两区——左侧「更多」触发器（含不可见 Tab 计数），右侧独立 `+`（保持原有新建 Tab 一键行为）。下拉向**上**弹出。
- 水平栏（`app:tabbar=top`）：在 `+` 按钮左侧增加「更多」触发器（图标 + 计数），下拉向**下**弹出。`+` 位置与行为不变。
- 计数 = 当前**不可见**的 Tab 数（折叠隐藏的 + 水平栏滚出视口的），为 0 时只显示图标、降不透明度。计数是提示，不过滤下拉内容。

### R2 下拉面板内容

- **全量 Tab 列表**，顺序 = `workspace.tabids` 物理顺序。
- 每行：左侧 badges（badge / agent 未读点 / flag 色）+ 名称（中间省略截断）+ hover 显示关闭 `✕`。
- 当前激活 Tab 高亮；当前不可见的 Tab 用弱化样式 + 标记区分。
- Tab 数 > 12 时面板顶部出现搜索框，按名称过滤（大小写不敏感）。
- 底部操作区：`+ 新建 Tab`、`收起未使用的 Tab`。
- 空态：`没有 Tab`。

### R3 交互

- 点击行：激活该 Tab + 标记本次启动已打开 + 关闭面板；水平栏中原本滚出视口的 Tab 切过去后自动滚入视口。
- `Esc`、点击面板外、选中任意项 → 关闭。
- 面板打开期间不改变主栏布局（不强制展开折叠 Tab），避免下方内容抖动。
- 面板关闭后恢复原有 hover 展开/收起逻辑（含原有延时）。
- 拖拽重排仍只在主栏进行，面板内不参与拖拽。

### R4 不破坏既有行为

- 两栏现有的点击/双击重命名/右键菜单/拖拽重排/hover 展开/`scrollIntoView` 跟随激活 Tab 行为不变。
- 水平栏宽度计算必须把新增按钮宽度计入，压窄后的 Tab 不得被新按钮遮挡。
- 面板不得影响 `OverlayScrollbars` 的行为与生命周期。

### R5 可维护性

- 两栏共用同一份下拉组件与同一份「Tab 行模型」计算（active / wasOpened / hasUnread / hidden），不再三处复制判定。

## Acceptance Criteria

- [ ] 垂直栏底栏出现「更多 · N」+ 独立 `+`；点开向上弹出全量 Tab 列表。
- [ ] 水平栏 `+` 左侧出现「更多」按钮（含计数）；点开向下弹出全量 Tab 列表。
- [ ] 下拉中点击任意 Tab 能切换过去并关闭面板；`✕` 能关闭对应 Tab。
- [ ] 搜索框在 Tab 数 > 12 时出现并能正确过滤。
- [ ] 计数正确反映折叠/溢出 Tab 数量，为 0 时降级显示。
- [ ] 面板打开/关闭不引起主栏 Tab 位置抖动，不影响原有的 hover 展开行为。
- [ ] 水平栏有 12+ Tab 且需要横向滚动时，Tab 不被「更多」按钮遮挡。
- [ ] 单元测试 + DOM 测试通过；两个 preview 增加溢出示例。
