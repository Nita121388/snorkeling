# PRD — 图片预览翻页：本层上一张/下一张 + 下一站跨文件夹

## Goal

图片预览块支持"上一张 / 下一张"翻页：默认只在**当前文件夹本层**内翻；翻到本层末尾时给出明确的「下一站」入口（下一个含图片的文件夹），单击进入；全程有位置反馈。顺序与目录预览所见一致。

## 用户已确认的决策

| 决策点 | 结论 |
|---|---|
| 翻页范围 | 默认**只翻本层**（当前图片所在目录的直接子文件） |
| 顺序 | **跟随目录预览排序**（所见即所得）：`preview:defaultsort` 为 `name`（字母数字升序）或 `modtime`（修改时间降序），与目录表格同一语义 |
| 跨文件夹入口 | 翻到本层末/首时，`›`/`‹` 原地变成「下一站/上一站」条目（显示目标文件夹名 + 图片数），**单击**进入（不用双击——双击已被缩放占用；不用 Ctrl——已被"在新块打开"占用） |
| 键盘 | `←`/`→` 本层翻页；`Shift+←`/`Shift+→` 跨站；`Home`/`End` 首尾 |
| 打开新 Tab | `Alt+→` / `Alt+←` 在新 Tab 打开上一/下一张 |
| 反馈 | 进入下一站时浮出 1.5s 提示（文件夹相对路径 + n/m）；角落常驻 `3 / 12` 计数；本层只剩 1 张时按钮提示 |

## Requirements

1. 翻页在**同一 block、同一 Tab 内原地换文件**（复用 `PreviewModel.goHistory`，白送历史栈回退）
2. 图片白名单：`png jpg jpeg gif webp avif bmp svg ico tiff heic`
3. 跳过目录：`.` 开头、`node_modules`、`.git`、`.cache`、`dist`、`build`、`.venv`、`__pycache__`、`target`
4. 上限：单站最多 5000 张、深度 8；超限截断并在 UI 提示
5. 列目录一次 RPC 一个目录（`filelist`），逐目录渐进填充：本层列表就绪即可翻页，子目录索引后台补齐——"下一步"永远不因索引未建好而卡住
6. 索引内存缓存 60s（key = connection + anchor + 排序），过期重建；`Shift+R`/刷新按钮手动失效
7. 键盘只在**缩放比例 = 1 且无文本选区**时生效（不抢缩放手势与选中）
8. 远程连接：列举必须透传 `connection`，不允许退化为本地路径

## Acceptance Criteria

- [x] 本层多图：`→`/`‹›` 逐张前进后退，顺序与目录预览默认排序一致（name 升序含数字段 `1,2,10`）
- [x] 本层只有 1 张：`›` 变为「下一站」；单击后进入下一含图文件夹第一张，且有 1.5s 浮出提示
- [x] `Shift+←/→` 直接跨站；`Home/End` 跳本层首尾
- [x] `Alt+→` 在新 Tab 打开下一张（不动当前 Tab）
- [x] 键盘在缩放≠1 或有选区时不翻页（缩放手势不受影响）
- [x] 无下一站（全树遍历完）：`›` 置灰，不循环
- [x] 大目录（>5000）截断 + UI 提示，无卡顿
- [x] 排序跟随 `preview:defaultsort`（name / modtime 两种都要对）
- [x] 单测：排序比较器与 TanStack `alphanumeric` 逐对一致、序列构造、边界
- [x] CDP 真机：真目录真图翻页 + 跨站 + 边界置灰，截图留证
- [x] tsc 无新增错误；相关 vitest 全绿

## 非目标（本版不做）

- 设置项（循环翻页 / 自定义排序开关）
- 跨 Tab 同步「当前是第几张」
- 按修改时间跨文件夹排序站点（站点始终按目录树名序）
- 缩略图墙
