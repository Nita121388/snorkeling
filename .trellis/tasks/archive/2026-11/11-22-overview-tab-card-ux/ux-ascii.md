## ② 组头 4 种状态谱

```
▾ Snorkeling                                    ●3 agents  [↗ 打开] [＋Agent]   ← 有 agent，展开
▸ Answer            2 块 · 无 agent                        [↗ 打开]            ← 普通折叠
▸ dump              未打开 · 1 块（灰）                     [↗ 打开]            ← 从来没点开过
▸ Base              空 Tab（没有块）                        [↗ 打开]            ← 真空 tab
  └ 一行浅灰：该 Tab 里没有可展示的块

组头部件：▾/▸ 折叠(整组记忆) 名称  计数徽章  [↗打开]  [＋Agent]
          ↑ 只有 ▾ 区域折叠；名称点击 = 折叠；[↗] = setActiveTab 跳过去
```

## ⑤ 过滤器语义矩阵（组数守恒）

```
                        组头数量        组内行           灰行(未打开)
[👁 关] [🤖 关]         全部 Tab       全部           正常显示
[👁 关] [🤖 开]         全部 Tab       只剩 agent     正常显示   ← 不再整组消失
[👁 开] [🤖 关]         仅"本次开过"    全部           灰行隐藏
```
