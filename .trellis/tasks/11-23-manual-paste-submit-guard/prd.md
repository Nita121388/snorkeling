# PRD：手工粘贴 + 回车被 agent TUI 吞掉的保护（可选，最低优先级）

> 父：`11-23-session-surface-fixes-1123`（优先级序 6，S）。前 5 项完成后再评估是否还痛。

## 问题

用户在新块里**手工**粘贴（Ctrl+V）+ 回车；pi 启动期吞回车 → 文本留在输入框，用户以为已发送。
我们只能观测，不能替用户按回车（那是他的输入）。

## 建议方案（待定，先记录）

- R1 观测：paste 事件后 N 秒内该块输入区仍有内容且 agentstatus 未进入 working → 在块头显示
  「可能未提交 · 补回车」一条提示；
- R2 一键补回车：走 `submitTermInput(blockId)`（已有函数），不重发文本；
- R3 只对 agent 块启用；不做自动补发（会重复投递）。

## 验收判据（数字）

- 真机：手工粘贴 5s 未提交 → 提示出现（DOM 断言）；点提示 → 输入框清空 + agentstatus 转 working。

## 不做

- 不自动按回车；不拦截用户粘贴。
