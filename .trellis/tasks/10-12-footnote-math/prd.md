# 子任务 3：脚注与数学（footnote-math）

## Goal
补齐两类「依赖已就位、只差渲染与样式」的高性价比块：**脚注**与**数学公式**。

## 关键事实
- **脚注**：`remark-gfm` 已经解析、sanitize schema 已放行 → **只缺渲染器与样式**（08 方案判定：最高性价比第一枪）
- **数学**：需要 `remark-math` + `rehype-katex`（新依赖）；`electron.vite.config.ts` 已有 katex 的 manualChunks 分支（说明生态已在）
- 思源的做法（可借鉴）：**「渲染 + 源码面板」单范式**覆盖 math/HTML/图表/嵌入 —— 即编辑该块时给出小源码输入区，而不是把它变成 contenteditable
- 思源主动关闭了 TOC / 脚注 / 定义列表 → 我们**要做**（这是差异化：脚注是标准 GFM，兼容性更好）

## Requirements
- R1 脚注渲染器：角标引用 `[^1]` 与定义 `[^1]: 文本` → 可点击跳转的角标 + 底部定义区，样式取自既有 token
- R2 脚注**编辑**：点击角标/定义块可编辑；`[^1]:` 标记在编辑态不露出（遵循零差异）
- R3 数学：行内 `$..$` 与块级 `$$..$$` 渲染（KaTeX）
- R4 数学**编辑范式**：采用「渲染 + 源码小输入区」（思源范式），**不**把公式塞进 contenteditable 直接编辑
- R5 往返：脚注与公式原文**逐字节保持**（不得被重排/转义）
- R6 sanitize 放行新增 tag/class（**遵守 schema 维护规则**：同一 tag 的同名属性只能出现一次，且测试必须 import 真实 schema）

## Acceptance Criteria
- [ ] 渲染：脚注引用/定义、行内/块级公式各自的四类 UI 测试
- [ ] 编辑：编辑态与预览态零差异；标记不露出
- [ ] 往返：含脚注与公式的文档往返逐字节一致；混合文档（脚注+公式+callout+列表）不互相破坏
- [ ] 样式：KaTeX 与脚注样式只用既有 token；无新增颜色
- [ ] 暗色模式：公式与脚注在暗色下可读（token 校验通过）
