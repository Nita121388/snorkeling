Common Text Quick-Tag Prototype 灯泡保存 → 再打标签 · 交互原型 v1

① 试试：选中下面任何一句文字NEW

选中文字后，右侧会出现 💡 灯泡按钮。点灯泡 → 点 “Add Selection to Common Text”，文字即被保存，且气泡不再一闪而过， 而是变成带 (Tag) 按钮的交互气泡。

② 试试：给刚保存的文字打标签

点气泡上的 (Tag) → 弹出标签编辑器。输入标签用 Enter 或逗号分隔； 点下方“常用标签”可直接添加；Esc 取消，点 Save Tags 保存。

③ 试试重复保存（合并标签）

下面这句在右侧列表里已存在带标签的版本：
Use npm run setup to install the toolchain
再选中它保存一次，会提示 Already exists，但同样可以点 (Tag) 给已有条目补标签（标签会合并，不会新增重复条目）。

保存后气泡停留 12 秒或直到你点别处/打标签完成；点文档空白处会收起气泡（已保存内容不丢失）。 右侧面板可核对每个条目的标签是否落盘。
