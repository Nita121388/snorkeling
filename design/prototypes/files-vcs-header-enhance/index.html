为什么这样设计
• 颜色：用 --success-color（4 套主题均为绿系），color-mix(success 45%, secondary) 保留灰调，不像纯绿那样像「新增成功」。不能用 accent：暗色绿、浅色紫、极简黑、暖色橙，语义会漂移
• 要「变动大小」：用 font-weight: 500 + transform: scale(1.012)，零布局影响，不会挤压右侧图标或提前截断
• 不打架：靠 :not(:hover) 限定，悬浮时彻底还原；只改 color / weight / transform，不碰 background / border
• 菜单去噪：移除「Open VCS Block」disabled 项（左键本来就是它），菜单只留真实可用操作
• 冗余强化：干净时版本管理图标加一个 5px 绿点，路径被截断时也能看出来
• 树内同步：目录树里每个项目文件夹也会显示状态标记，详见 ../files-vcs-tree-status/
• 实时准确：状态以 repo.status（无变更且无 untracked）为准，复用 VCS 缓存，仅 Git 生效
