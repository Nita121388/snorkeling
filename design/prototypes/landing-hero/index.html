The workflow

Stay in the terminal

Open, edit, compare and commit without leaving the window, and launch an agent from the same pane.

  • TerminalSplit panes, and SSH sessions that survive a restart.
  • FilesEdit remote files in the built-in editor, without leaving the pane.
  • VCSDiff and file history in their own blocks, beside the code.
