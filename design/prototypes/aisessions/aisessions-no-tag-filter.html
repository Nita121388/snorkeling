原型: AI Sessions — Untagged Note Filter
在 FilterPanel 的 Tags 行加 SegTrack [Any · Untagged] 作为新的"标签存在性"筛选维度.

根因: 后端 summaryMatchesList (pkg/aisessions/index.go:418) 与 sqlite 端 List (sqlite_index.go:1070) 都只调 sessionTagsContainAll (tags.go:84), 它只能表达"包含全部所选 tag", 没有"无任何 tag"的入口. 前端 tagFiltersAtom: string[] 同款无法表达. 所以这是 RPC 入参到 SQL 都缺的一阶能力, 不止 UI 缺一项.

语义: Untagged = NormalizeSessionTags(summary.Tags).length === 0. 不用 Boolean(note) — 纯 "#fix" 这种纯 tag note (无 prose) 按 CLAUDE.md "session.note 语义 — tags live inside the note string", 应算"有标签", 不能被错归到"无标签".

形态: 常驻 SegTrack, 不藏菜单. Untagged 与具体 tag chip 互斥 (Variant D): 逻辑上永远空结果, UI 自动复位.
关系: 与 Marked/Date/Path 是 AND 复合 (Variant C), active strip 一键清.
