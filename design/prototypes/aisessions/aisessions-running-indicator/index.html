为什么右侧是元信息行

元信息行本来就是「这台会话现在什么状况」那一行（来源 / 时间 / 消息数 / 大小）。 运行态属于同一类信息，且右侧是行内唯一不被 hover 才出现的 Resume/Copy 打扰的位置。

真代价：默认宽度下 +1 行

实测元信息行（来源 / GUI Chat / 时间条 / Created / 2 个热度格）在 320px 默认宽度下刚好占满 1 行。 加右侧徽章后：320px 15 → 38px、384px 15 → 35px，只有 520px 才是 15 → 15。 试过绝对定位 + padding 预留，更差（38 → 73），因为预留宽度直接挤压左侧。 所以这是产品取舍：要零成本就用 nowrap 策略（左侧截断），要信息完整就接受 +1 行。
