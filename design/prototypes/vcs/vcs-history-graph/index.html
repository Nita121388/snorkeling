设计说明

维度当前（vcs-history-tab.tsx）本原型
提交图无（纯文本单列列表）泳道图：节点 + 贝塞尔连线，分支各一色一泳道，HEAD 节点带光环
ref 徽章无HEAD → main / origin/main / tag / branch 彩色徽章，颜色与泳道一致
作者纯文本首字母头像（生产：email → GitHub/GitLab 头像）+ 名字
hash纯等宽文本mono chip，hover 行时出现复制按钮
展开▸/▾ + 文件列表保留展开变更文件（M/A/D 状态色 + ±行数），展开块左缘泳道连线延续
过滤/分页keyword + 日期 + 分页保留；泳道按当前页计算（翻页处断线为已知取舍）
主题跟随 app token深/浅双主题，全部走 token（右上角切换）
