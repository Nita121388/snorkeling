VCS Block — Multi-repo Switcher

Design prototype mirroring frontend/app/view/vcs/vcs.tsx + vcs-tabs.tsx. The backend already returns all detected repos (RemoteVcsRepositoriesCommand); the frontend only renders activeRepo with no switcher. This prototype adds a repo selector in the VCS header row. Switch a repo below and watch the branch / KPIs / tabs follow.
