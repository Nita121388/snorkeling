问题：① 固定列 78/120/110px + gaps ≈ 320px，470px 面板下标题只剩 ~70px，标题全被截断； ② 描边胶囊无语义色，与分支页 ↑绿 ↓红 的既有语汇不一致； ③ 无表头、无 hover、无行分隔层次，读起来像裸数据表；松 ISO 时间戳占宽却信息量低。

1上游 + 分叉合成一条 sync bar：去描边，用 surface-soft 底面分层；↑绿 / ↓红 沿用分支页语汇，0 值降到 55% 透明度作为弱提示。
2提交行改两行：标题整宽（不再和作者/时间抢宽度），元信息下一行 10.5px muted，松 ISO 时间戳换相对时间（5 分钟前，hover 显示绝对时间）。
3左 2px 语义轨：Outgoing 绿、Incoming 红（hover 才点亮到 55%，静止更轻）；分组标题从裸文字改为 标签 + 计数 chip + 发丝线。

保留单行高度（28px），只把「方向箭头 + 相对时间」放上来，hash 移到 title 里。 密度最高、改动最小；代价是看不到 hash，扫读时少了"这条是不是我刚提的那个 commit"的锚点。

共性规则（A/B 都适用）
· 语义色只用于方向，不用来整行染色：--success = ahead/Outgoing，--error = behind/Incoming，文字仍走 text-secondary。
· Behind = 0 时弱化到 opacity .55，仍保留可见（用户要确认"我没落后"），但不再是一个抢眼的描边胶囊。
· Ahead 与 Behind 都为 0 时，整条 sync bar 右侧换成 ✓ 已同步（上面可切状态看效果）。
· Pull / Push 按钮 disabled 逻辑沿用现状（behind <= 0 / ahead <= 0），A 方案里再加一条：新增计数变化时对 ↑/↓ 数字做 200ms 高亮脉冲（可选 P2）。
· 长标题一律 text-overflow: ellipsis + title 全量，不做换行，保持行高可预测（虚拟滚动/高度稳定）。
