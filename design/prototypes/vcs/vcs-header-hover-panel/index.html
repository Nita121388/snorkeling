Git vs SVN 面板差异（面板文案均为英文，与现有 VCS 视图一致）

项目GitSVN
徽章GITSVN
分支行显示本地分支名（如 main）无分支概念，不显示
远端状态↓落后 / ↑领先 pill远端变更文件数（svn status -u）

全场景状态机

场景行为
非 repo 路径（kind=none）不弹面板，保留原生 title；点击仍打开 VCS Block（内提示 No repos found）
检测中（懒加载首触）先渲染 "Detecting..."，resolve 就绪后原地更新（复用 directoryVcsResolveCache）
resolve 失败/超时Resolve Failed + Copy Debug Info（与右键菜单降级一致）
嵌套多仓库includeparent=true 返回多个 repo，面板分组列出、各自按钮
连接断开endIconButtons 在 connStatus != connected 时不渲染，天然覆盖
Windows 盘符根跳过 resolve（与 preIconButton 排除逻辑一致）
sync 成功后清除该 path 缓存条目并刷新面板计数；失败走 setErrorMsg 通道
触屏/无 hover无 hover 则无面板；点击打开完整 VCS Block，功能不丢失

交互时序（对齐真实 Tooltip 组件参数）

  • hover 图标 350ms 后弹面板（openDelay，防滑过误触发）
  • 移开图标/面板 250ms 宽限后收起（Tooltip 关闭延迟 300ms 同款体验）
  • 首次悬浮才触发 resolve RPC（statuslimit 50 轻量调用），结果进 conn+path 内存缓存，与右键菜单共享
  • 点击图标本体 = openVersionControlBlock()，与现状完全一致
