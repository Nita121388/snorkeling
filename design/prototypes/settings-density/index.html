Common Text syncs across your machines — one transport, one copy of the data.

Transport

recommended
Local folder
commontext.json in a cloud-drive folder; picks up external changes.
Git repository
Private repo, periodic commits — real history, visible conflicts.
Set an access token first (Settings → Secrets).
Self-hosted service
Your own sync server over HTTP/WebSocket, token auth.
Enter the server URL and token first.
Off · local only
No transport. Items stay on this machine.
Switching from Local folder to Git repository
Both sides already hold data, and their revision numbers come from different transports so they cannot be compared. Pick which side to trust for items that differ — nothing is deleted either way.
Runs one full re-sync before saving
This device wins — local items overwrite the remote; remote-only items are pulled in. Remote wins — remote items overwrite local; local-only items are pushed as new.

File path

▸ Advanced conflicts · scope · maintenance

Conflicts

Merge per row recommended
Auto-merge when possible; only a same-field double edit becomes a conflict.
Newest wins
Take the newer updatedat and silently overwrite the older side.
Always ask
Stop and ask on every conflict; syncing stays paused until resolved.

Scope

Common Text
This release syncs Common Text only. Other domains (settings, notes, sessions) are out of scope.
Sync deletions (tombstones)
When off, a delete stays local and the other machine pushes the item back.

Maintenance

Full re-sync
Ignore the local cursor and reconcile the whole remote snapshot once.
Reset sync state
Clears the local cursor and rev cache only. Items and the remote file are untouched.
Draft — nothing is written until Save.
