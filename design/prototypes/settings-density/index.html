Agent Notifications

agentnotifications
Snorkeling raises a native toast when an agent finishes or asks for input. These switches control how often that happens.
Agent notifications
Master switch for every agent toast.
Notify when an agent finishes
A working agent became idle — the turn completed.
Notify when an agent needs input
The agent is blocked, for example on an approval prompt.
Notify even while Snorkeling is focused
By default a toast is skipped when a Snorkeling window has focus.
Idle threshold
Wait until the keyboard and mouse have been idle this long before notifying. 0 notifies right away.
sec
Cooldown
Repeat toasts of the same kind inside this window are merged into one summary. 0 disables the cooldown.
