设计决策备注

  1. 默认「仅此会话」：替换掉当前 Save to template 默认勾 true 的行为 —— 改全局模板必须是显式选择，不是默认副作用。
  2. 三种范围都写当前会话的初值：建完即可填，体验与今天一致；模板只管可见性。
  3. 数据模型：AgentPropertyDefType 增加 Scope string（""=全局 / "agent:pi"=按 Agent）， 缺省空 = 全局，旧数据零迁移；toPropertyDefs 只并入 scope 匹配的模板项。
  4. 「某个 Agent」目前按 origin 粒度（pi / codex / opencode）。如果要按 model 或 persona 粒度，scope 编码改为 agent:<origin>:<model> —— 待拍板。
  5. Save to template 复选框删除，被三选一取代；md 预览属性卡不传 schema，不受影响。
  6. Non-goals：模板管理界面、既有属性「改范围」的行菜单项（第二期 Property menu → Scope）。
