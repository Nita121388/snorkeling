## 目的

人设系统三个核心交互面的可交互原型：**右键创建**、**🎭 widget 悬浮登场**、**人设名册 Block**。
所有数字（注入 token、记忆条数、配额）均为演示值，真实值以设计文档 §7 规则（渐进披露三层金字塔 + 2K 硬顶）为准。

## 三个场景（顶部切换）

### A · 右键创建 + 向导（§4）

- 会话行**右键**（或按 `P`）→ 「🎭 设为新人设…」
- 向导第 1 步：emoji picker、名字 → **目录名自动 slug 化**（中文小词典演示）、据点二选一（全局根目录 / 单独指定）、记忆初稿来源勾选
- 向导第 2 步：**真实 scaffold 文件树预览**（展示即创建），含 AGENTS.md 自动生成说明与 inbox.md 提议区

### B · 🎭 悬浮登场（§5 / §7）

- 右侧 widget 条 **hover 🎭 >300ms** → 弹窗（点击 🎭 图标 → 场景 C 名册）
- 弹窗三段：选 Agent（谁上身）→ 选人设（谁登场，● 登场中/○ 空闲）→ **注入开关**
- 勾选「注入本次主工作目录」→ 登场后首条提示带 `[登场上下口] 本次主工作目录: …`；不勾 = 纯人设任务
- 「开始登场」→ 新 block：头部显示 cwd = 人设据点，body 显示渐进披露注入摘要（L0 名册 + L1 本人摘要 ≈ token 数）

### C · 人设名册 Block（§6 / §4.5）

- 顶部 **⚡ 待批准区**：agent 提议创建的人设（含配额提示），批准/驳回
- 列表：状态点、休眠折叠区（💤 dormant）、新建入口
- 详情：职责（CHARTER）、据点（全局/单独）、**记忆统计**（facts/lessons/playbook + 注入 token 硬顶条）、登场史、createdBy 徽标（人建 vs ⚡AI 自建）
