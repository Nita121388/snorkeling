🎯 设计要点

呼吸感：list 行内 padding 从 py-1(4px) → py-2.5(10px)，行间留白翻倍，单行高度从 ~30px 涨到 ~52px。
字号可读：title 12→13 且 font-weight 600；preview 11→12 改 monospace 与 editor 视觉同源；tag chip 10→11。
对称外边距：modal padding pt-6 pb-3 不对称改为 20px/16px，且统一内 gap-3。
聚焦态强化：editor 与 search input 聚焦时加 box-shadow: 0 0 0 3px var(--highlight-bg) 软光晕，更明确活跃边界。
pinned 视觉化：除左侧 thumbtack 图标外，给整行加 2px accent 左 border，置顶预览一眼可辨。
blur 折叠延时：原 onBlur 立即 setEditorExpanded(value.includes("\n"))，鼠标从 editor 移到下方 Send 中途触发 blur → editor 收缩 → 按钮位移 → 点空。改为延迟 600ms 折叠， onFocus 取消挂起的 timer。
明暗双主题：浅色用真实 theme.scss:192-249 暖沙色系 —— 背景 #ebe5d9、modal 米白 #fffdf8、border #ded8ca、文字 #4c3924/#675033/#777167，accent 紫 #a76fca，--highlight-bg = accent @ 20% (rgba(167,111,202,0.20))，--hover-bg = accent @ 10%，--editor-bg = term-background #faf7f0。

🗂️ Master-Detail 交互策略（绕开"点击 = 插入 vs 查看"冲突）

输入左侧列表右侧详情
hover 行视觉 hover 态立即同步该行全文（浏览模式）
click 行插入 editor 光标同步选中行（md-active 高亮）
↑↓ 键盘选中切换同步详情（不插入）
Enter插入 editor不变
详情区 title 输入 / Pin / All tags / body / toolbarstopPropagation() — 绝不触发行 click → editor
详情区 Pin 按钮就地 toggle pinned，复刻 save-dialog.tsx:207-219 样式（accent 高亮 + thumbtack）
详情区 All tags 面板某 tag就地加/移该 tag，复刻 save-dialog.tsx:238-250 的"All tags"面板
详情区 Insert 按钮单击显式插入（兜底，等价于行 click）
核心不变量
详情区是只读控件，与列表 click→editor 主路径事件隔离。

对应真实组件
详情区把当前 commontext-save-dialog.tsx 的编辑面（title + Pin 按钮 + tag chips + 正文）以「就地只读」而非"另开 Dialog"形式常驻右侧 —— 编辑入口收敛到详情区，省去再开 modal 的二次跳转。

状态优先级
displayed = hover ?? active —— 鼠标在列表上时跟随 hover（即看即走），离开后回退到最近一次 click 选中行（即点过即留住），不会出现"鼠标一抖详情乱跳"。

响应式回退
≤760px 时改为上下堆叠：列表 max-height 240px 可纵向滚，详情在下方独立滚；移动端 hover 缺位也仍可用 click 选中。
