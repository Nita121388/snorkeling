🎯 融合设计原则
1
Combine + Overview = 同一个面板
不再有 Dashboard 和 Overview 两个独立视图。左侧面板同时承载两者：实时预览（当前 Tab）→ 展开行；全局浏览（跨 Tab）→ 折叠行。一个按钮，一个视图。
2
跨 Tab，与 Overview 同源
与 Overview 一样遍历所有 tab 的 blocks。数据源完全一致（使用 useOverviewBlocks(workspace)），不重复加载。
3
当前 Tab = 可展开预览 · 其他 Tab = 精简摘要
当前 tab 的 agent 和 terminal 行可以展开实时预览（SubBlock 嵌入 xterm.js）。非当前 tab 的 block 显示精简状态行，点击可跳转。
4
过滤条控制显示范围
All / Agents / Terminals 过滤器决定显示哪些类型的 block。不影响右侧 layout。
5
排除逻辑与持久化
每行 hover 显示 ✕，点击排除。排除列表 localStorage 持久化。排除项淡化显示，可恢复。
6
跳转聚焦
点击任意行 → 关闭面板（或保持打开）→ 聚焦原始 block 并高亮。与现有 Overview 的 jumpToBlock() 相同模式。
