10 · Launcher 快速启动 + Settings

镜像源 frontend/app/view/launcher/ · frontend/app/view/waveconfig/ — 三列启动面板、键盘可达、设置密度与未保存状态。

现状问题
P1
启动入口按类型平铺。 「最近 / 快捷动作 / Agent 目标」混在一个列表，找 codex 要滚过 20 个终端配置。
P2
键盘只有部分可达。 ↑↓ 能选，但 ↵ 行为随上下文变化，没有可视化选中行 + 提示。
P3
设置没有密度梯度。 13 寸屏与 27 寸屏同一套 44px 行高，前者一屏只看 5 行。
P4
未保存改动无提示。 改完直接关窗即丢失，没有脏状态条 / 离开确认。
优化方案
S1
Launcher 三列定宽。 最近（≤5）· 快捷动作（分组）· Agent 目标（vendor 分组）。搜索框置顶，跨列统一过滤。
S2
选中行 + 底部快捷键图例。 选中行左 2px accent 条；底部常显 ↵ 打开 ⌘↵ 新窗口 Esc 关闭。
S3
密度三档。 紧凑 5px / 标准 9px / 宽松 14px 行内边距；按窗口高度自动建议，用户可覆盖。
S4
脏状态条。 有任何未保存改动 → 底部出现「n 项未保存 · 保存 / 丢弃」；关窗二次确认。
