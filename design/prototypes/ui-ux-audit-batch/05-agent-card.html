05 · Agent 状态 chip / 悬浮卡

镜像源 frontend/app/agent-status/ — 三密度 chip、色盲可辨编码、悬浮卡按钮命中层、运行时长统一。

现状问题
P1
仅靠颜色区分状态。 working 蓝 / done 绿 / stale 紫 —— 色觉障碍用户在列表密度下无法区分 idle 与 stale。
P2
chip 尺寸跨面板不统一。 列表 16px、看板 18px、悬浮卡 20px，切换时视觉跳动。
P3
悬浮卡放大按钮点不动。 与 Block 信息卡同源：被终端 canvas 的 link-layer 吞点击（HANDOFF 25/26 那个红灯）。
P4
运行时长格式混乱。 出现过 00:07 这类计时器样式，与 3min21s 混用。
优化方案
S1
形状 + 动效双编码。 working 脉冲环、done 实心圆、stale 斜纹方块、idle 中空；颜色失效仍可辨。
S2
三密度 variant。 d1 = 10px 点（列表密集）· d2 = dot+label（看板/卡片）· d3 = +runtime（悬浮卡/详情）。
S3
悬浮卡命中层修复。 与 02 一致：portal + z-index 1000 + 终端 pointer-events:none；动作区 pointer-events:auto。
S4
runtime 统一格式。 纯函数输出：7s / 3min21s / 1h12min / 2d3h；绝不出现 00:07。
