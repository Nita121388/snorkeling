02 · Block 头部 + 信息卡 + 最小化列

镜像源 frontend/app/block/ — 图标密度、hover latch、信息卡被 xterm link-layer 吞点击、最小化入口。

现状问题
P1
信息卡按钮点不动。 HANDOFF 记录：悬浮卡「放大」按钮在真实指针下被 xterm 的 link-layer canvas 盖住，只有 JS click() 生效 —— 层级/命中问题。
P2
头部图标平铺无优先级。 高频（关/分裂/溢出）与低频（复制/笔记/设置）同权重，30px 高度里挤 7–9 个图标。
P3
hover latch 丢失。 指针从标题移到图标时通过 0px 间隙，图标瞬间消失，中途必失败一次。
P4
最小化入口远离 Block。 最小化后只能靠右下浮动按钮找回，与「哪个块被最小化」无视觉关联。
优化方案
S1
命中层修复。 信息卡 portal 到 body，z-index: 1000；终端 canvas 的 link-layer 在卡片打开时设 pointer-events:none；卡片动作区显式 pointer-events:auto。
S2
图标分组「3 + 更多」。 常显：关闭 / 分裂 / 溢出；其余收进 ⋯ 菜单，按使用频次排序。
S3
hover latch 300ms。 头部留 4px 保持区；离开后 300ms 才淡出，指针跨越间隙不闪断。
S4
左侧最小化 icon 列。 与 WidgetsBar 对称；每块一个图标 + 右上计数 badge，hover 显示 flyout 列表。
