现状问题
P1
未变更区整段直出。 ±3 行上下文之外的长段未变更代码也全部渲染，300 行文件要滚 12 屏。
P2
滚动即丢锚点。 工具栏（repo / 分支 / fetch）不固定，下滚后要回到顶上才能切 repo。
P3
提交图看不出父子。 泳道线有了，但 hover 不会高亮祖先链，「这个提交是哪条线上的」要自己数。
P4
行号是单列。 删除行的旧行号被复用，评审时对不上旧文件行号。
优化方案
S1
未变更区折叠。 超过 6 行的未变更段折叠为一行 ⋯ 42 行未变更 · 点击展开，点击或 O 展开。
S2
sticky 分组工具栏。 repo 切换 · 分支 · fetch 分三组 | 分隔，滚动全程固定在顶部。
S3
祖先链高亮。 hover 提交 → 该提交的全部祖先泳道提亮 + 相关行加底色，其余淡至 30%。
S4
双列行号。 旧号（−）+ 新号（+）并列；删除行只占旧号列，新增行只占新号列。
