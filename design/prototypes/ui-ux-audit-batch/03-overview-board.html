03 · Overview 看板 + 时间线

镜像源 frontend/app/session-overview/ — 卡片信息架构、空列占位、筛选与三视图切换。

现状问题
P1
空列吃掉横向空间。 5 列常显 + 横向 snap，空状态列仍占 208px，窄窗口一屏只看到 3 列。
P2
卡片信息平权。 标题、repo、状态、时间同字号同色，扫视时无法在 0.3s 内抓到「卡在哪」。
P3
缺少「只看未完成」。 done 列堆积后仍需横向滚动穿越，没有列内筛选。
P4
视图切换无记忆。 board/list/timeline 每次回到默认 board；时间线缺少「今天」参考线。
优化方案
S1
空列收窄为 40px rail。 保留可发现性（竖排计数），把 168px 还给有内容的列。
S2
卡片三级信息架构。 ① 标题（2 行）② 状态 chip + repo/path ③ 时间。左侧 3px 状态条 + 左侧色仅作辅助。
S3
筛选 pill + 列头计数。 「仅看未完成」可一键过滤，列头 3/7 直接给出分布。
S4
视图记忆 + 今天参考线。 localStorage 记忆上次视图；时间线加 TODAY 竖线 + hover 十字准线/绝对时间。
