08 · WidgetsBar 右侧工具条

镜像源 frontend/app/workspace/widgets.tsx — 命中热区、active 指示、折叠态与 Block 侧栏的对称性。

现状问题
P1
命中热区太小。 实际图标 14px，视觉看着可点，实际命中只有 14×14，边缘 7px 都是死区。
P2
图标不解释自己。 悬停无 flyout 名称，新用户面对 ◈ ▤ ▸ 一排符号只能逐个试。
P3
active 态靠颜色对比弱。 选中 widget 只变色，54px 窄条里 13px 图标变色不显眼。
P4
折叠后彻底隐身。 收起后 0px 宽，不知道右侧还有内容；与左侧最小化列结构不对称。
优化方案
S1
28px 命中热区。 图标 14px 视觉，但按钮热区 28×28；hover 背景 6px 圆角浮现。
S2
flyout 名称 + 说明。 hover 200ms 后左侧浮出标签（名称 + 次要说明），点击可穿透。
S3
active 左侧 3px 指示条。 几何指示 + accent 双通道；带计数 badge（如 agent 运行数）。
S4
折叠留 8px 感温边。 折叠后保留 8px 条 + 状态点（有活动 widget 时 accent 高亮）；hover 展开。
