06 · Files 预览 + 目录树 VCS 标记

镜像源 frontend/app/view/preview/ · frontend/app/treeview/ — 面包屑导航、VCS 标记、只看改动、空态。

现状问题
P1
路径只能看不能用。 头部一长串路径是纯文本，不能点某一段跳转，也没有「复制路径 / 在终端打开」的常驻位。
P2
VCS 标记不解释自己。 目录树里的颜色小点没有 tooltip / 图例，新用户不知道 M/A/U 意味着什么。
P3
改动被淹没。 大目录里 3 个改动文件埋在 60 行里，没有「只看改动」入口。
P4
空目录直出白板。 无引导、无动作，用户对着空区块不知道下一步。
优化方案
S1
breadcrumb 可点 + 动作分组。 每段路径可点击跳转；右侧动作分三组（固定 ⭐ / 常用 ⇗⧉ | 分隔 | 更多 ⋯）。
S2
VCS 标记 6px 方点 + tooltip。 M 橙 / A 绿 / U 红 / Q accent；hover 出 modified · +42 −7；树底有图例。
S3
「只看改动」开关。 开启后未改动行降为 35% 透明度，改动文件保持全亮 —— 不整树重排，保位稳定。
S4
空态三件套。 图标 + 一句话说明 + 1–2 个动作（新建文件 / 在此处打开终端）。
