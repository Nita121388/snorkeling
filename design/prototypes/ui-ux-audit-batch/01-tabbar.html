01 · TabBar / Workspace Switcher

镜像源 frontend/app/tab/ — 标签溢出、悬浮信息卡截断、状态编码与键盘可达性。

现状问题
P1
悬浮信息卡被顶部截断。 贴住窗口顶边时向下弹出的卡片超出视口，HANDOFF 记录的 N-1105-tab-hover-clip 即此问题。
P2
标签一多就压到不可读。 flex 均分导致宽标签被挤成 20–30px 的纯图标条，活动标签和普通标签同样被压缩。
P3
「+ 新建」与右侧开关漂移。 放在可滚动轨道里，标签多时被推出视口或被 scrollbar 遮挡。
P4
状态只靠颜色。 working / done / stale 三个小圆点色相接近（色弱不可辨），且没有运行时长。
优化方案
S1
三段式固定布局。 左固定入口（侧栏/概览）· 中间可滚动轨道 · 右固定操作区（+ / WidgetsBar）。两端永不参与压缩。
S2
active tab 保护 + 溢出计数。 活动标签最小 120px 不压缩；其余标签折叠进「+N」下拉，附键盘序号。
S3
信息卡视口翻转。 锚点上方 < 卡片高 + 12px 时向下翻转；横向按 8px 夹紧；portal 到 body 避免被容器裁切。
S4
状态双层编码。 形状 + 颜色：working 脉冲环、done 实心圆、stale 斜纹方块；hover 卡内补运行时长。
