Agent Card · 合体版

C 的 icon + 左右行布局 + 文本简化  ·  D 的 30px 头像块 + 标题引用块  ·  状态 / 收藏 / 放大收进右上角

这一版改了什么

  • 身份用头像块：30px 圆角方块承载 Logo / emoji / 文字徽标三态，比 18px 裸图标更认得出「谁在说话」。
  • 标题变主体：左 2px 状态色竖线做引用块，2 行截断 + hover 全文，不再和属性行同一灰。
  • 右上三件套：状态、收藏、放大同一基线右对齐；星标常驻弱色，不再独占一行属性。
  • C 的行骨架：每行「icon + label 左 / value 右」，一行一条信息，去掉逐行分割线与 Empty 斜体。
  • 文本简化：first_user_message → First message 并归位到副标题（与 model 同行）、Empty → —、绝对时间 → 相对时间（hover 绝对值）、Add property / AI auto-fill 收进底部单行。
  • 结果：同数据下卡高 296px → 实测（340 宽、标题 2 行），4 条属性一行不少，但值都可一眼扫完。
现状（实测 @340）296px6 属性行 + 2 按钮行 + id 行

五种状态

状态色只出现在 6px 圆点、chip 描边与标题引用线上，不染整卡。

宽度与内容形态

300px 极限窄、380px 舒适宽、有 tags + note 的填充态、以及折叠属性后的极简态。
