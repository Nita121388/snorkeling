Agent Card · 美化方案集

镜像 frontend/app/view/term/agent-hover-card.tsx + info-card.scss + session-note-section.tsx；8 张卡 = 现状基线 + 7 套参考成熟产品的信息层级重排

推荐组合

A 的层级（相对时间 / 星标上行 / 空值不占行）+ B 的状态条与 mono meta + E 的指标三列。三者都是 CSS 为主的局部改动，可以分别落地，不冲突。

不建议整卡采用

F 品牌玻璃在一屏十几个 hover 卡里会变成彩色噪声；C Raycast 的分组头在真机上比在原型里重，适合弹窗（AgentCardModal）而不适合 hover 预览。

要解决的真问题

现状 6 行属性 + 2 个按钮 + session id 把卡片撑到 300px 高，而真正会看的只有 标题 / 状态 / 更新时间 / tags。美化 = 砍行 + 让剩下的行有主次，不是加装饰。
