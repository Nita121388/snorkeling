原型 PROTOTYPE 文件夹索引徽标 — 三个功能点：① index.md 状态表 ② badges.js 用户自定义脚本（脚本可覆盖表格）③ Agent 改完索引后定向刷新 Block。右侧可调开关、样式、索引、脚本与刷新。
MyDocs

实验开关（Preview 设置）

索引徽标 preview.folderIndexBadges 总开关，默认关闭。关闭时不读索引、不跑脚本，树零影响。
启用自定义脚本 badges.js 数据源 2：脚本决定每个文件项的显示逻辑，可覆盖索引表格。
模拟索引缺失 打开 = index.md 不存在 / 读不出：表格源静默降级，脚本源不受影响。

目录装饰提供者（插件接口）

FolderIndexBadges active
数据源 1：读目录内 index.md，解析状态表。失败返回空 Map，不报错。
UserScriptBadges disabled
数据源 2：sandbox 里跑 badges.js，每个文件项调用一次 decorate(entry)。单条失败只跳过该条。
