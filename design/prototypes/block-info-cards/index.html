Block Info Cards · 五种 Block 的开篇卡

与 agent-id-card 同一套证件视觉语法：横版卡身、左照片环 + 右信息行、时间条区、底部编号行； 照片环颜色 = 状态色，异常态才盖章（正常态不盖章，克制）。 覆盖五个核心 block：term(SSH) / web / preview / vcs / sysinfo。 应用内文案英文，中文仅为评审注释。Token 与 frontend/app/theme.scss 对齐。

每张卡上方有状态 pills 可切换场景；右侧切换 App 主题与桌面明暗。

Connection Card

term + connection

语义： 登机牌。SSH 连上远端的一瞬间亮出：这是哪台机器、谁在飞、飞了多久。 照片位 = 连接图标（或主机名首字母），环色 = 连接状态；时间条 = 连接稳定性轨迹（在线/掉线/重连）；底部 = host key 指纹。

统一语法（与 Agent ID Card 对齐）

元素规则
卡身横版 max-width 560、左照片环(84px) + 右信息行、uppercase 小标签右对齐、底部编号行等宽字体 + 复制
照片环环色 = 该 Block 的核心状态色；连接/加载中脉冲，完成/静止不动。特殊化两种：环形仪表(sysinfo)、favicon(web)
章正常态不盖章，仅异常/需注意态出现（Dropped / Not secure / Draft / Conflict / Overload），克制不喧哗
时间条同一区域三种变体：① 分段轨迹(连接稳定性/编辑历史，与 Agent 卡完全同款) ② 柱状(web 加载/vcs 提交活跃) ③ 迷你曲线(sysinfo 负载)
底部编号行各 Block 最值得复制的那一个 id：指纹 / URL / 路径 / HEAD sha / hostname
生命周期与 Agent 卡一致：block 首开亮卡 → 首个内容到达/点击后折叠为 header 徽标 → 随时展开

状态色语义（环色优先级）

Card环色 = ？正常需注意(warn)异常(error)
Connection连接状态connected → done 绿connecting → working 蓝脉冲dropped → error 红 + 章
Site安全状态HTTPS valid → done 绿mixed content → warn 橙无 TLS → error 红 + 章
File脏状态saved → done 绿unsaved draft → warn 橙 + 章read-only → idle 灰
Repo同步状态in sync → done 绿ahead/behind → warn 橙conflict → error 红 + 章
System负载水位<50% → done 绿50-80% → warn 橙>80% → error 红 + 章

字段 → 数据来源（对齐真实代码）

Card来源
ConnectionblockData.meta.connection（term.tsx）+ wconfig connections（host/user/auth）+ connstatusoverlay.tsx 状态与延迟；指纹来自 known_hosts 校验结果
SiteWebViewModel：title/favicon/URL、load 指标（performance API）、证书状态与 tracker 拦截计数
Filepreview-model.tsx（文件信息、行数、语言）+ preview-dirty-state.ts（未保存 hunk 数）+ fs stat（size/mtime）
RepoVcsViewModel（branch/ahead-behind/changes/HEAD）+ commits 近 14 天聚合 + pipeline 状态（vcs-pipelines-tab）
Systemsysinfo.tsx：cpu/mem/disk/net/uptime 采样序列（cpuplot 同源数据直接复用为 sparkline）

分期

  • P0：静态卡 + 状态环/章 + 底部复制（数据全部现成，纯前端拼装；优先 Connection 与 File）
  • P1：时间条三变体接真实序列数据；dd-action 行接现有入口（Remote config / History / Changes）
  • P2：折叠徽标与 Agent 卡统一成一个通用 chip 组件；卡片进入动画打磨
