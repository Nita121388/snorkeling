Common Text
Compose text. Click + to add a new item to the top, then edit it on the right; click a row (or press Enter) to edit it; Insert drops it into the editor.

新增点 1 · 列表右侧的「时间 / 次数」列

没有新增整行 meta，而是把信息压进真实行已有的右侧空位（真实行原本只有 hover 才出现的插入按钮）： 第一行 次数，第二行 更新时间。 行高与真实 py-1.5 保持一致，且不再出现「used 24×」这类文字。

创建时间 / 最近使用 / 完整时间戳放在行的 title 悬浮提示里，避免在窄左栏里挤三段文字。

新增点 2 · 排序控件与搜索态切换

遵循「能用图标表示的不用文字」：排序是一组纯图标按钮，含义走 title 与 aria-label，不占左栏宽度。

这一条对齐真实代码：searchCommonTextComposeItems 内部先按 sortCommonTextItems 建 baseOrder，再用相关度打分重排，baseOrder 只作并列次序。 试着在搜索框输入 report 观察切换。

落地前要定的 3 件事（原型已按推荐值实现）

  1. 排序作用域：浏览态用用户排序，搜索态相关度优先（否则搜索会「吃掉」排序）。
  2. 使用次数口径：现在 Copy 与行内插入按钮都不调 recordCommonTextUse，上线前要补这两个写入点，否则次数长期偏低。
  3. 排序函数注入：不改 sortCommonTextItems 本体（它还管写盘顺序与键盘导航下标）， 新增独立函数并作为 options 传进搜索函数。

可试交互

  • 切排序：看「置顶」是否仍在前、从未使用 的条目在 下落到最后
  • 搜索 report / email：排序组转灰、右侧出现 ，置顶不再强制最前
  • 点 tag chip / untagged：筛选与排序叠加
  • 点行：右栏切到该条，可改标题、切 Pin、删除
  • 每个图标按钮都有 title，鼠标停一下即可读含义
