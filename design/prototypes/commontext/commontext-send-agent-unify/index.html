Design intent

同一套选择语言

让用户在两处用同一种方式做选择：看得见名字、选中状态明确、位置与动作稳定。

  • 保留 CommonText 的信息骨架聚焦块 / 新建、Agent、Tab、目录、后台执行一个不少。
  • 模型下拉 + 可见路径列表28px 模型选择、可滚动路径行、左 2px 选中轨，直接沿用 New Agent 形态。
  • 落点只表达一次删除重复目标卡，把完整落点收进 footer 的路径摘要。
