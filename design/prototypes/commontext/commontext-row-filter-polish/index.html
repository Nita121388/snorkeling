这版原型要拍板的四件事
  1. 行高 = 52px（两行）：标题一行，摘要 + 标签同行。真实组件当前 ROW_HEIGHT=44， 而带标签的行实测需要 ≈62px（标题 16 + 摘要 16 + 标签 18 + 上下 padding 12）， 第三行被 overflow:hidden 裁掉 —— 切到「44px（现状）」档可以直接看到被裁的标签。
  2. 64px（三行）备选：标签独占第三行，标签多且需要一眼看全时用；代价是可视行数减少 （列表每次少 20%）。两档都用常量行高，虚拟化 ROW_HEIGHT/spacer 数学不用改结构。
  3. 筛选区收敛成一行：创建者分段（同壳内靠底色分隔）+ 机器下拉 chip + 排序 chip（显示当前排序名， 不再只给 5 个图标）+ 无标签开关 + 标签条（单行横向滚动、右缘渐隐）。 对比现状的「搜索 + 创建者行 + 排序行 + 无标签/标签行」四层，省 2 行纵向空间给列表。
  4. 窄态自动折两行：宽度 < 约 700px 时筛选行按「创建者+机器 / 排序+无标签+标签」折行， 标签条独占一整行 —— 切到「窄 700」档查看。
