规则 1 · 只有 Agent Block 可发 硬约束

Send 目标收窄为 term 块且带 agent:* meta。普通终端不再出现在目标里；聚焦普通终端时「聚焦块」项禁用并给出提示。

规则 2 · 目标展示 Agent Card 新增点

目标行直接用 agent 小卡：头像 / 标题 / provider · model / 状态 chip / 运行时长，字段对齐 agentcardmodal.tsx。

规则 3 · 三项正交选择 已改

  • 选择 Agents：profile，默认跟随聚焦块
  • 选择 Type：默认当前 Tab，下拉可选其他 Tab，+ 新建 Tab
  • 选择 Folder：新建块的项目目录（cwd），默认聚焦块目录，可选其他项目目录或浏览

选择目标 · 显式二选一 2026-11-11 已改

不再只靠「三项全等」推导：聚焦块 / 新建 是两枚显式 chip，✓ 跟实际落点走。选了与聚焦块同款 agent 时也能「同款新建」。默认 focused；点「新建」= 强制 create。

发送时机 · 两套语义 本轮新增

  • 立即：注入（聚焦块）或建块后注入，注入后补回车提交（只 paste 不提交 = agent 收不到）。
  • 延迟 ≤30 分钟：内存队列 + TTL；到点目标块仍在 → 注入 + 回车；块没了 → 通知，不重试、不落任务系统。
  • 定时（一次 / 每天 / cron）：复用 ScheduledTask（pkg/scheduler，cron/interval/once/daily/weekly + headless CLI runner）；不依赖 TUI / 块在场，跨重启有效；结果进任务历史 + 系统通知，不进交互会话。

外部 Agent 接入 能力已备

Agent Control Surface 已把 UI 能力映射成 MCP stdio 工具（snorkeling_*，1:1 映射既有 wsh RPC）。本轮需求新增两个门面：

  • snorkeling_commontext_send：按正文 / 条目 id 发送（限「新建块」或 headless，禁止注入任意已存在会话）。
  • snorkeling_scheduledtask_create | list | delete：直接映射既有 RPC；另加 wsh scheduledtask create|list|run 薄封装给 shell 型 agent。

解析规则（仍成立） 核心

focused 且 Agent = 聚焦块 agent 且 Type = 当前 Tab 且 Folder = 聚焦块目录 → 直接注入聚焦块；其余（含 mode=create）→ 按所选 Type + Folder 新建 agent block。
