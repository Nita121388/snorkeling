# Snorkeling 加载态样本 · 20 种水下骨架动画

打开方式：直接双击 `index.html`（单文件、零依赖、无需构建）。

主题「深海 / 浅滩」、速度「1× / 0.25×」、动效「开 / 关」三个开关在顶栏。
点击任意样本会放大展示，并**从当前样式表里抽出该动画的 CSS**，可一键复制。

## 为什么是这套

Snorkeling 的等待时刻原本只有一种语言：灰色占位条 + 通用 shimmer。这个原型把「加载」
换成一整套取自水下世界的动作词汇——光在水里的折射、气泡上浮、潮位退去、珊瑚分枝、
声呐扫过——每一种都对应一种**等待的语义**，而不是同一种扫光换 20 个速度。

设计之外的两个约束：

- **强度分级**。不是每个界面都受得了几何动效。样本按存在感分为三级：
  ●○○ 阅读界面安全（长文、列表常驻）、●●○ 短等待（<2s）、●●● 一次性扫描 / 非关键区。
  这条分级写在每张卡的右下角，落地时先按界面性质选级，再选形。
- **只用便宜属性**。transform / opacity / background-position / filter，
  不做逐帧 JS、不做 canvas、不做 layout 触发。`prefers-reduced-motion` 下全部退回静态骨架。

## 实现要点

- 骨架块只有三个尺寸（6 / 8 / 11px）与两个圆角（3 / 5px），宽度按真实文案长度的比例给，
  落地时保持「值占真实尺寸」的原则，数据回来时布局不跳动。
- 每个样本的 CSS 自包含：`[data-anim="xxx"]` 前缀 + 该样本独有的 `@keyframes`。
  着色只用 `background-image` / 一个覆盖层，不改结构。
- 浅色主题（`body[data-theme="shallow"]`）对高光做了单独补偿：
  焦散、气泡改成白色高光，磷光改成品牌绿，热泉改成深色羽流，鱼群改成深色剪影。
- 循环型动画的复位藏在淡出段（最后 3–10%），避免重启时闪跳；
  显示型动画（涟漪、珊瑚、织网、面镜除雾、深度表）也一样。
- 无 JS 也能看到完整的静态骨架；`body[data-motion="off"]` 与
  `prefers-reduced-motion: reduce` 会清掉所有动画、隐藏光束/气泡/鱼群覆盖层。

## 与项目既有规范的偏差（需要知道）

`references/app-screens.md` §11 的现行约定是「loading 用平灰条、不用 shimmer 渐变」。
这 20 个样本是**主动的设计探索**，不是默认实现。落地的建议：

1. 列表 / 表格 / 长文这类常驻界面，只取 ●○○ 与 ●●○ 里的低强度样本（沙纹、洋流、呼吸、磷光）；
2. ●●● 只在一次性扫描（声呐、织网）或非关键区（空看板、图表占位）使用；
3. 全面落地前，先挑 1–2 个真实位置（如 AISessions 列表首载、图表卡）做对照。

## 第三轮迭代（用后反馈：生物画得太潦草）

第一版用 CSS 色块/边框三角拼生物，龟壳、鱼鳍、珊瑚分叉在这个尺度下拼不出来。
这一轮改为**内联 SVG 单色剪影**，每只动物画完整（仍在 `data-anim="school"` 作用域内，一键复制 CSS 仍能拿到整套样式）：

- **鱼** —— 柳叶身 + 后掠尾 + 眼点；
- **鲨鱼** —— 流线体 + 后掠背鳍 + 歪尾（上叶长下叶短，鲨鱼标志）+ 胸鳍 + 眼；58px，9.5s（比小鱼略快，不再抢戏）；
- **海龟** —— 椭圆壳 + 三条盾片纹（壳色的负形）+ 头 + 会摆的前后鳍；52px，13s 巡游；
- **水母** —— 伞盖下沿荷叶边 + 三根弧线触须；原地上浮下沉；
- **珊瑚礁景** —— 沙床弧带 + 四丛分叉珊瑚（端头圆帽，像珊瑚虫）+ 三条摆动海草；
- 颜色只用 `--bar-hi` / `--raised` 两个 token；浅滩主题另配一档深灰绿剪影色（浅底下默认对比只有 1.2:1，必须单独补）；
- 3x 缩放真浏览器逐只验证过两个主题下的可读性。

## 两轮评审记录

**第一轮（自动检测 + 自查）**：10 FAIL / 5 WARN → 5 FAIL / 2 WARN。

- 内容不居中（grid 只有 max-width、无 `margin-inline:auto`）→ 全部居中，顶栏同步对齐 1140px。
- 标题 30px 撑不起首屏 → 72px（手机 52px），副标题 18px。
- 卡片靠 1px 描边分隔 → 改为 tone-step（`--surface` / `--surface-2`），hover 只用底色变化。
- 灰字 4.3:1 不达标 → `--faint` 提到 `#86988f`（深海）/ `#5b6962`（浅滩）。
- 「放大查看」默认不可见，reduced-motion 下永远看不到 → 常显 0.55 透明度。
- 手机端顶栏折成两行、左右边距 18 / 32 不等 → 隐藏副标签、边距对齐 32 / 32。
- 遗留 FAIL 均为载体属性，保留：潜水灯的光束本身是渐变（就是设计对象）、按钮与弹窗的 1px
  （真实控件与浮层）、样本卡被计为 icon 卡（这是样本目录）、无照片（CSS 动画画廊）、
  12px 标签（app 规范允许 11–12px 的标签层级）。

**第二轮（独立评审 agent + 真机三宽度复检）**：评审结论——「有主见的产物，但网格没做完」。逐条修：

- 同排卡片标题基线错位（预览高度不等，像没写完的瀑布流）→ `.tile` 改 flex 列、`.stage` 用 `flex: 1` 拉伸，配合一行式描述，同排卡片完全等高。
- 20 条描述句式模板化（反复「适合……」）→ 全部改成 ≤14 字名词短语，用途压缩成独立短标签（会话卡 / 表格 / KPI…）并入强度行。
- 常驻「放大查看」×20 纯噪音 → 换成单个 ↗ 箭头（hover 提亮，整卡可点）。
- 图例暗点不可见（三组像同一状态）→ 提高 off 点底色，编码恢复可读。
- 手机 H1 断行孤字（第二行只剩一个「态」）→ 手动断成「20 种 / 水下加载态」，降字号到 46px。
- 工程备注占了首屏权重 → 挪到底部 colophon。
- 静态帧分不开的近亲样本 → 焦散改成卡片骨架、气泡改成纯列表行、洋流加表头行、等深线加锚点条，拉开块体几何。
- 评审另指出：热泉 / 等深线 / 涟漪 / 沙纹在静态截图里几乎全黑。这些在真浏览器里是循环动画，静态帧截到空态属正常，不修改，记录在此。

两轮后的遗留检测项及理由（均为载体属性，不是缺陷）：

- 渐变填充 24 处：就是设计对象本身（水下的光斑、羽流、光束、流线）；
- 1px 描边：真实按钮 / 弹窗面板 / 声呐环 / 等深线，均为功能元素；
- 等宽字体：弹窗里的 CSS 代码块；
- 毛玻璃：唯一的 sticky 顶栏；
- 无照片 / 无视频：CSS 动画画廊，内容即绘制本身；
- 12px 标签：app 规范允许 11–12px 的标签层级；
- off-centre 告警：检测器把文字块边缘当页边距造成的测量误差，截图里左右对称。
